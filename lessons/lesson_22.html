Phase 1
The iframe Element
💡 Concept

An <iframe> (inline frame) lets you embed another webpage inside your own page. The src attribute is the URL to embed. The title attribute is required for accessibility. You can control the size with width and height. Note: some websites (like Google) block iframes for security reasons, but YouTube, Google Maps, and many others allow it.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head><title>Iframes</title></head>
  <body>
    <h1>Embedded Content</h1>

    <!-- Embed a YouTube video -->
    <h2>A YouTube Video</h2>
    <iframe
      src="https://www.youtube.com/embed/dQw4w9WgXcQ"
      title="YouTube video player"
      width="560"
      height="315"
      allowfullscreen>
    </iframe>

    <!-- Embed Google Maps -->
    <h2>A Google Map</h2>
    <iframe
      src="https://www.google.com/maps/embed?pb=!1m18!1m12!1m3!1d3956.6!2d3.9!3d7.4!2m3!1f0!2f0!3f0!3m2!1i1024!2i768!4f13.1!3m3!1m2!1s0x0%3A0x0!2zN8KwMjQnMDAuMCJOIDPCsDU0JzAwLjAiRQ!5e0!3m2!1sen!2sng!4v1"
      title="Map of Ibadan"
      width="560"
      height="350"
      style="border-radius:12px; border:0;"
      loading="lazy"
      allowfullscreen>
    </iframe>
  </body>
</html>

Phase 2
Styling Iframes
💡 Concept

Iframes can be styled with CSS just like any other element. Use border: none; or border: 0; to remove the ugly default border. Add border-radius to round the corners. Set width: 100% to make it fill its container. The loading="lazy" attribute tells the browser to load the iframe only when it comes into view — great for page speed.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Styled Iframes</title>
    <style>
      .iframe-card {
        background: white;
        border-radius: 16px;
        overflow: hidden;
        box-shadow: 0 4px 14px rgba(0,0,0,.1);
        margin: 24px 0;
      }
      .iframe-card p {
        padding: 12px 16px;
        font-size: 14px;
        color: #64748b;
        margin: 0;
        border-top: 1px solid #e2e8f0;
      }
      .iframe-card iframe {
        width: 100%;
        height: 300px;
        border: none;
        display: block;
      }
    </style>
  </head>
  <body style="font-family:Arial; padding:30px; background:#f1f5f9;">
    <h1>My Embedded Videos</h1>

    <div class="iframe-card">
      <iframe
        src="https://www.youtube.com/embed/dQw4w9WgXcQ"
        title="My chosen video"
        loading="lazy"
        allowfullscreen>
      </iframe>
      <p>📺 This video is embedded using an &lt;iframe&gt; element.</p>
    </div>
  </body>
</html>

My Embedded Content Page

Build a content page that embeds a YouTube video and a Google Map inside styled iframe cards.

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>My Embedded Content — Lesson 22</title>
    <style>
      * { box-sizing: border-box; }
      body { font-family: Arial, sans-serif; background: #f1f5f9;
             padding: 30px; max-width: 800px; margin: 0 auto; }
      h1 { color: #ea4f21; }
      .embed-card {
        background: white; border-radius: 16px; overflow: hidden;
        box-shadow: 0 4px 16px rgba(0,0,0,.08); margin-bottom: 30px;
      }
      .embed-card iframe { width: 100%; height: 340px; border: none; display: block; }
      .embed-caption {
        padding: 14px 18px; font-size: 14px; color: #475569;
        border-top: 1px solid #e2e8f0;
      }
    </style>
  </head>
  <body>
    <h1>My Embedded Content Page</h1>
    <p>Using &lt;iframe&gt; to embed a YouTube video and a Google Map.</p>

    <h2>📺 My Favourite Video</h2>
    <div class="embed-card">
      <!-- Replace the src with YOUR chosen YouTube embed URL -->
      <iframe
        src="https://www.youtube.com/embed/dQw4w9WgXcQ"
        title="My chosen video"
        loading="lazy"
        allowfullscreen>
      </iframe>
      <p class="embed-caption">
        🎬 [Write a description of why you chose this video]
      </p>
    </div>

    <h2>🗺️ Where I Live</h2>
    <div class="embed-card">
      <!-- Replace with YOUR city's Google Maps embed -->
      <iframe
        src="https://www.google.com/maps/embed?pb=!1m18!1m12!1m3!1d251806.0!2d3.8!3d7.4!2m3!1f0!2f0!3f0!3m2!1i1024!2i768!4f13.1!3m3!1m2!1s0x10380d44693a9f85%3A0xaf7f3e6c72c36ef0!2sIbadan%2C%20Oyo%20State!5e0!3m2!1sen!2sng!4v1"
        title="Map of Ibadan, Nigeria"
        loading="lazy"
        allowfullscreen>
      </iframe>
      <p class="embed-caption">
        📍 Ibadan, Oyo State, Nigeria — where Techbase Academy is based.
      </p>
    </div>
  </body>
</html>
