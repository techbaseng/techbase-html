Phase 1
Form Basics and Input Types
💡 Concept

A <form> collects information from the user. action says where data goes. method is get or post. The <input> tag's type controls input kind: text, email (auto-validates), password (hides text), number, date, checkbox, radio, submit. Try: add required to any input — the form won't submit without it!

index.html 
<!DOCTYPE html>
<html lang="en">
  <head><title>Form Inputs</title></head>
  <body>
    <h1>Form Input Types</h1>
    <form action="#" method="post">
      <p>Text:     <input type="text"     placeholder="Your name"></p>
      <p>Email:    <input type="email"    placeholder="you@example.com"></p>
      <p>Password: <input type="password" placeholder="••••••••"></p>
      <p>Number:   <input type="number"   min="1" max="100" value="18"></p>
      <p>Date:     <input type="date"></p>
      <p>Checkbox: <input type="checkbox"> I agree to the terms</p>
      <p>Radio:
        <input type="radio" name="grade" value="jss"> JSS
        <input type="radio" name="grade" value="sss"> SSS
      </p>
      <p><input type="submit" value="Submit Form"></p>
    </form>
  </body>
</html>

Phase 2
Labels, Select and Textarea
💡 Concept

Every input must have a <label> for accessibility. Link label to input: for="id" on label and id="id" on input — clicking the label then focuses the input. <select> creates a dropdown with <option>s. <textarea> creates a multi-line text area.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Labels and Select</title>
    <style>
      form { max-width:500px; }
      label { display:block; font-weight:bold; margin:14px 0 4px; }
      input, select, textarea {
        width:100%; padding:10px; border:1.5px solid #cbd5e1;
        border-radius:8px; font-size:15px; font-family:Arial;
      }
      input:focus, select:focus, textarea:focus {
        outline:none; border-color:#ea4f21;
      }
    </style>
  </head>
  <body>
    <h1>Contact Form</h1>
    <form>
      <label for="name">Full Name *</label>
      <input type="text" id="name" name="name"
             placeholder="Tunde Awoyemi" required>
      <label for="email">Email *</label>
      <input type="email" id="email" name="email"
             placeholder="you@example.com" required>
      <label for="course">Which course?</label>
      <select id="course" name="course">
        <option value="">-- Choose --</option>
        <option value="html">HTML Basics</option>
        <option value="css">CSS Mastery</option>
        <option value="js">JavaScript</option>
        <option value="python">Python</option>
      </select>
      <label for="msg">Your Message</label>
      <textarea id="msg" name="msg" rows="4"
                placeholder="Type your message..."></textarea>
    </form>
  </body>
</html>
✏️ Your Task

Add a <label> to every input. Click each label — the input should get focus. Add a <select> dropdown and a <textarea>. Mark required fields with required and an asterisk (*) in the label.

Phase 3
Validation and Fieldsets
💡 Concept

HTML5 has built-in validation — no JavaScript needed for basic checks! required (must fill in), minlength/maxlength (text length), min/max (number range). <fieldset> groups related inputs visually; <legend> gives the group a title.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Validation</title>
    <style>
      fieldset { border:2px solid #e2e8f0; border-radius:12px;
                 padding:20px; margin:20px 0; }
      legend { color:#ea4f21; font-weight:bold; padding:0 8px; }
      label  { display:block; font-weight:bold; margin:12px 0 4px; }
      input  { width:100%; padding:10px; border:1.5px solid #cbd5e1;
               border-radius:8px; font-size:15px; }
      input:invalid { border-color:#f87171; }
      input:valid   { border-color:#4ade80; }
      button { background:#ea4f21; color:white; border:none;
               padding:12px 24px; border-radius:8px; font-size:15px;
               font-weight:bold; cursor:pointer; margin-top:10px; }
    </style>
  </head>
  <body>
    <h1>Validated Form</h1>
    <form>
      <fieldset>
        <legend>Personal Details</legend>
        <label for="fname">First Name *</label>
        <input id="fname" type="text" minlength="2" maxlength="50" required>
        <label for="age">Age *</label>
        <input id="age" type="number" min="5" max="100" required>
      </fieldset>
      <fieldset>
        <legend>Account Details</legend>
        <label for="mail">Email *</label>
        <input id="mail" type="email" required>
        <label for="pw">Password (min 8 chars) *</label>
        <input id="pw" type="password" minlength="8" required>
      </fieldset>
      <button type="submit">Register</button>
    </form>
  </body>
</html>
✏️ Your Task

Add minlength="2" to your name input, required to email, and min="5" max="120" to an age number input. Try submitting — browser shows errors automatically! Group fields into two <fieldset>s.

Phase 4
Styling a Complete Form
💡 Concept

A well-styled form dramatically increases completion rates. Key rules: generous padding on inputs, coloured border on :focus, labels above inputs (never beside on mobile), prominent submit button, and width: 100% on all inputs for mobile friendliness. Use the :invalid and :valid CSS pseudo-classes for instant feedback as the user types.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Styled Form</title>
    <style>
      * { box-sizing:border-box; }
      body { font-family:Arial; background:#f1f5f9;
             display:flex; justify-content:center;
             align-items:center; min-height:100vh; padding:20px; }
      .card { background:white; border-radius:18px; padding:36px;
              width:100%; max-width:480px;
              box-shadow:0 8px 32px rgba(0,0,0,.1); }
      h1 { color:#ea4f21; font-size:1.5rem; margin:0 0 6px; }
      .sub { color:#94a3b8; font-size:13px; margin:0 0 24px; }
      .field { margin-bottom:18px; }
      label { display:block; font-weight:700; font-size:13px;
              color:#334155; margin-bottom:5px; }
      input, select, textarea {
        width:100%; padding:12px 14px; font-size:14px;
        border:1.5px solid #e2e8f0; border-radius:10px;
        outline:none; font-family:Arial; background:#f8fafc;
        transition:border-color .2s;
      }
      input:focus, select:focus, textarea:focus {
        border-color:#ea4f21; background:white;
      }
      button[type="submit"] {
        width:100%; background:#ea4f21; color:white;
        border:none; padding:14px; border-radius:10px;
        font-size:16px; font-weight:700; cursor:pointer; margin-top:6px;
      }
      button[type="submit"]:hover { background:#c23d15; }
    </style>
  </head>
  <body>
    <div class="card">
      <h1>Contact Techbase</h1>
      <p class="sub">We reply within 24 hours.</p>
      <form>
        <div class="field">
          <label for="n">Full Name *</label>
          <input id="n" type="text" required placeholder="Tunde Awoyemi">
        </div>
        <div class="field">
          <label for="e">Email *</label>
          <input id="e" type="email" required placeholder="you@example.com">
        </div>
        <div class="field">
          <label for="m">Message</label>
          <textarea id="m" rows="4" placeholder="How can we help?"></textarea>
        </div>
        <button type="submit">Send Message ✉️</button>
      </form>
    </div>
  </body>
</html>

🏗️ Build It!
My Contact Form

Build a beautiful fully-validated contact form with labels, fieldsets, multiple input types, and mobile styling.

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Contact Me — [Your Name]</title>
    <style>
      * { box-sizing:border-box; margin:0; padding:0; }
      body { font-family:Arial,sans-serif; background:#f1f5f9;
             min-height:100vh; padding:40px 20px; }
      .page { max-width:580px; margin:0 auto; }
      h1 { color:#ea4f21; font-size:2rem; margin-bottom:6px; }
      .lead { color:#64748b; margin-bottom:30px; }
      .card { background:white; border-radius:18px; padding:32px;
              box-shadow:0 4px 20px rgba(0,0,0,.08); }
      fieldset { border:1.5px solid #e2e8f0; border-radius:12px;
                 padding:20px 22px; margin-bottom:22px; }
      legend { color:#ea4f21; font-weight:bold; font-size:15px; padding:0 8px; }
      .field { margin-bottom:16px; }
      label { display:block; font-weight:700; font-size:13px;
              color:#475569; margin-bottom:5px; letter-spacing:.03em; }
      input, select, textarea {
        width:100%; padding:11px 14px; font-size:14px;
        border:1.5px solid #e2e8f0; border-radius:9px;
        outline:none; font-family:Arial; background:#f8fafc;
        transition:border-color .2s, background .2s;
      }
      input:focus, select:focus, textarea:focus {
        border-color:#ea4f21; background:white;
      }
      .row { display:flex; gap:14px; }
      .row .field { flex:1; }
      .checkbox-row { display:flex; align-items:center; gap:10px;
                      font-size:14px; color:#475569; }
      .checkbox-row input { width:auto; }
      button[type="submit"] {
        width:100%; background:#ea4f21; color:white; border:none;
        padding:14px; border-radius:10px; font-size:16px;
        font-weight:700; cursor:pointer; margin-top:6px;
        transition:background .2s;
      }
      button[type="submit"]:hover { background:#c23d15; }
    </style>
  </head>
  <body>
    <div class="page">
      <h1>Get in Touch 👋</h1>
      <p class="lead">Fill in the form below and I'll reply as soon as I can.</p>
      <div class="card">
        <form action="#" method="post">
          <fieldset>
            <legend>Personal Details</legend>
            <div class="row">
              <div class="field">
                <label for="fname">First Name *</label>
                <input id="fname" type="text" required minlength="2" placeholder="Tunde">
              </div>
              <div class="field">
                <label for="lname">Last Name *</label>
                <input id="lname" type="text" required minlength="2" placeholder="Awoyemi">
              </div>
            </div>
            <div class="field">
              <label for="email">Email *</label>
              <input id="email" type="email" required placeholder="you@example.com">
            </div>
          </fieldset>
          <fieldset>
            <legend>Your Message</legend>
            <div class="field">
              <label for="subject">Subject</label>
              <select id="subject" name="subject">
                <option value="">-- Choose a topic --</option>
                <option>General Enquiry</option>
                <option>Course Information</option>
                <option>Technical Support</option>
                <option>Partnership</option>
              </select>
            </div>
            <div class="field">
              <label for="msg">Message *</label>
              <textarea id="msg" rows="5" required
                        placeholder="Write your message here..."></textarea>
            </div>
            <div class="field">
              <label class="checkbox-row">
                <input type="checkbox" required>
                I agree to receive emails from [Your Name] *
              </label>
            </div>
          </fieldset>
          <button type="submit">Send Message ✉️</button>
        </form>
      </div>
    </div>
  </body>
</html>
