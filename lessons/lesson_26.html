Phase 1
The Viewport and Fluid Widths
💡 Concept

A responsive website looks good on every screen. The first step is the viewport meta tag: <meta name="viewport" content="width=device-width, initial-scale=1.0">. Then use percentage widths instead of fixed pixels — width: 100% fills the container. Use max-width to stop content stretching too wide on large screens.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Responsive Basics</title>
    <style>
      * { box-sizing: border-box; }
      body { font-family: Arial; margin: 0; padding: 16px; }
      .container { max-width: 800px; margin: 0 auto; }
      img { width: 100%; height: auto; border-radius: 10px; }
      h1 { font-size: clamp(1.5rem, 5vw, 2.5rem); }
    </style>
  </head>
  <body>
    <div class="container">
      <h1>This Heading is Fluid!</h1>
      <p>Resize the browser and watch this heading change size with clamp().</p>
      <img src="https://via.placeholder.com/800x300" alt="Responsive image">
    </div>
  </body>
</html>

Phase 2
CSS Media Queries
💡 Concept

Media queries apply different CSS at different screen sizes. Syntax: @media (max-width: 768px) { ... }. Common breakpoints: 480px (phones), 768px (tablets), 1024px (laptops). Mobile-first approach: write mobile CSS first, then add min-width queries for larger screens.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Media Queries</title>
    <style>
      * { box-sizing: border-box; }
      .cards { display:flex; flex-wrap:wrap; gap:16px; padding:20px; }
      .card  { background:white; border-radius:12px; padding:20px;
               border:1.5px solid #e2e8f0; width:100%; }
      @media (min-width: 600px) { .card { width: calc(50% - 8px); } }
      @media (min-width: 900px) { .card { width: calc(33.33% - 11px); } }
    </style>
  </head>
  <body style="background:#f8fafc;">
    <div class="cards">
      <div class="card"><h3 style="color:#ea4f21">Card 1</h3>
        <p>1 column → 2 → 3. Resize to see!</p></div>
      <div class="card"><h3 style="color:#0284c7">Card 2</h3>
        <p>Pure CSS media queries — no JavaScript.</p></div>
      <div class="card"><h3 style="color:#10b981">Card 3</h3>
        <p>Mobile-first design approach.</p></div>
    </div>
  </body>
</html>

Phase 3
Responsive Images with picture
💡 Concept

The <picture> element serves different images at different screen sizes — a smaller image on mobile saves data and loads faster. <source media="(max-width:600px)" srcset="small.jpg"> for mobile. The <img> inside is the fallback. Always set width:100% on images for fluid scaling.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Responsive Images</title>
    <style>
      picture img { width:100%; height:auto; border-radius:10px; }
      .container { max-width:700px; margin:0 auto; padding:20px; }
    </style>
  </head>
  <body>
    <div class="container">
      <h1>Responsive Images</h1>
      <picture>
        <source media="(max-width: 600px)"
                srcset="https://via.placeholder.com/400x300/ea4f21/fff?text=Mobile">
        <img src="https://via.placeholder.com/700x250/0284c7/fff?text=Desktop"
             alt="Responsive image — changes with screen width">
      </picture>
      <p>Shrink browser below 600px — image switches to orange mobile version!</p>
    </div>
  </body>
</html>

🏗️ Build It!
My Responsive Page

Build a fully responsive page: fluid layout, 3-breakpoint media queries, and a responsive picture element.

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Responsive Page</title>
    <style>
      * { box-sizing:border-box; margin:0; padding:0; }
      body { font-family:Arial,sans-serif; background:#f1f5f9; }
      header { background:#ea4f21; color:white; padding:20px 24px; }
      header h1 { font-size:clamp(1.4rem,4vw,2rem); }
      nav { background:#0f172a; display:flex; flex-wrap:wrap; padding:8px 16px; }
      nav a { color:rgba(255,255,255,.75); text-decoration:none; font-size:14px;
              font-weight:600; padding:8px 12px; }
      picture img { width:100%; height:auto; display:block; }
      .container { max-width:960px; margin:24px auto; padding:0 20px; }
      .grid { display:flex; flex-wrap:wrap; gap:16px; }
      .card { background:white; border-radius:14px; padding:22px;
              box-shadow:0 2px 8px rgba(0,0,0,.06); width:100%; }
      .card h3 { color:#ea4f21; margin-bottom:8px; }
      .card p  { color:#475569; font-size:.9rem; line-height:1.7; }
      footer { background:#0f172a; color:rgba(255,255,255,.5);
               text-align:center; padding:20px; font-size:13px; margin-top:30px; }
      @media (min-width:600px)  { .card { width:calc(50% - 8px); } }
      @media (min-width:900px)  { .card { width:calc(33.33% - 11px); } }
    </style>
  </head>
  <body>
    <header><h1>📱 My Responsive Website</h1></header>
    <nav>
      <a href="#cards">Cards</a>
      <a href="#about">About</a>
    </nav>
    <picture>
      <source media="(max-width:600px)"
              srcset="https://via.placeholder.com/600x300/ea4f21/fff?text=Mobile+View">
      <img src="https://via.placeholder.com/1200x300/ea4f21/fff?text=Desktop+View"
           alt="Hero — changes with screen size">
    </picture>
    <div class="container" id="cards">
      <h2 style="margin:24px 0 16px;">What I Learned</h2>
      <div class="grid">
        <div class="card"><h3>📐 Fluid Widths</h3>
          <p>% widths and max-width instead of fixed pixels.</p></div>
        <div class="card"><h3>📱 Media Queries</h3>
          <p>@media rules change layout at 600px and 900px.</p></div>
        <div class="card"><h3>🖼️ Responsive Images</h3>
          <p>picture element serves the right image per screen.</p></div>
        <div class="card"><h3>✍️ Fluid Typography</h3>
          <p>clamp() scales font size between min and max.</p></div>
        <div class="card"><h3>📦 Flexbox Grid</h3>
          <p>flex-wrap turns a row into a responsive grid.</p></div>
        <div class="card"><h3>📏 Viewport Meta</h3>
          <p>Without this, mobile browsers ignore all our CSS.</p></div>
      </div>
    </div>
    <footer>© 2025 [Your Name] | Resize me to see responsive magic!</footer>
  </body>
</html>
