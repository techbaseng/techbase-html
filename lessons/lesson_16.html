Phase 1
Basic Table Structure
💡 Concept

An HTML table is built with several tags working together. <table> is the container. <tr> is a table row. <td> is a table data cell. <th> is a table header cell — it is bold and centred by default. Wrap the header row in <thead> and the data rows in <tbody> for good structure.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head><title>Tables</title></head>
  <body>
    <h1>My Timetable</h1>

    <table border="1" style="border-collapse: collapse; width: 100%;">
      <thead>
        <tr>
          <th>Day</th>
          <th>9:00 AM</th>
          <th>11:00 AM</th>
          <th>2:00 PM</th>
        </tr>
      </thead>
      <tbody>
        <tr>
          <td>Monday</td>
          <td>Maths</td>
          <td>English</td>
          <td>HTML Coding</td>
        </tr>
        <tr>
          <td>Tuesday</td>
          <td>Science</td>
          <td>History</td>
          <td>PE</td>
        </tr>
        <tr>
          <td>Wednesday</td>
          <td>Art</td>
          <td>Music</td>
          <td>CSS Coding</td>
        </tr>
      </tbody>
    </table>
  </body>
</html>

Phase 2
Table Borders and Styling
💡 Concept

By default tables have no visible borders. Adding border="1" on the <table> tag adds a basic border, but the best way is CSS. border-collapse: collapse makes borders merge into single lines (removes the double-border look). You can also use padding on cells, alternate row colours with CSS, and make the header row stand out with a background colour.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Styled Table</title>
    <style>
      table { width: 100%; border-collapse: collapse; font-family: Arial; }
      th { background-color: #ea4f21; color: white; padding: 12px; text-align: left; }
      td { padding: 10px 12px; border-bottom: 1px solid #e2e8f0; }
      tr:nth-child(even) { background-color: #f8fafc; }
      tr:hover { background-color: #fff3ef; }
    </style>
  </head>
  <body>
    <h1>Top Students</h1>
    <table>
      <thead>
        <tr>
          <th>Name</th><th>Score</th><th>Grade</th>
        </tr>
      </thead>
      <tbody>
        <tr><td>Amina</td><td>98%</td><td>A+</td></tr>
        <tr><td>Tunde</td><td>95%</td><td>A</td></tr>
        <tr><td>Chidi</td><td>91%</td><td>A</td></tr>
        <tr><td>Fatima</td><td>88%</td><td>B+</td></tr>
      </tbody>
    </table>
  </body>
</html>
✏️ Your Task

Style your timetable: give the <th> elements an orange background and white text. Add padding to all cells. Use tr:nth-child(even) to give alternate rows a light grey background. Add a tr:hover rule that highlights the row when you move the mouse over it.

Phase 3
Colspan and Rowspan
💡 Concept

Sometimes you want a cell to span multiple columns or rows. colspan="2" on a <td> makes it take up 2 columns. rowspan="2" makes it take up 2 rows. These are very useful for merged header cells or creating visual groupings in your data.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Colspan and Rowspan</title>
    <style>
      table { border-collapse: collapse; font-family: Arial; }
      th, td { border: 1px solid #cbd5e1; padding: 10px 14px; }
      th { background: #ea4f21; color: white; }
      .merged { background: #fff3ef; font-weight: bold; }
    </style>
  </head>
  <body>
    <h1>Exam Results</h1>
    <table>
      <tr>
        <th rowspan="2">Student</th>
        <th colspan="2">Term 1</th>
        <th colspan="2">Term 2</th>
      </tr>
      <tr>
        <th>Maths</th><th>English</th>
        <th>Maths</th><th>English</th>
      </tr>
      <tr>
        <td class="merged">Amina</td>
        <td>95</td><td>88</td>
        <td>97</td><td>92</td>
      </tr>
      <tr>
        <td class="merged">Tunde</td>
        <td>82</td><td>90</td>
        <td>85</td><td>91</td>
      </tr>
    </table>
  </body>
</html>
✏️ Your Task

Create a table where the top-left cell spans 2 rows (use rowspan="2") and the top-right two cells each span 2 columns (use colspan="2"). This is the same pattern used in real exam result tables!

Phase 4
Table Caption and Accessibility
💡 Concept

The <caption> tag gives a table a visible title displayed above it. The scope attribute on <th> tells screen readers whether it is a column header (scope="col") or a row header (scope="row"). Good tables also have a summary or aria-label for accessibility. Tables should only be used for data — never for page layout!

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Accessible Table</title>
    <style>
      table { border-collapse: collapse; font-family: Arial; width: 100%; }
      caption { font-weight: bold; font-size: 1.1rem;
                margin-bottom: 8px; color: #ea4f21; }
      th[scope="col"] { background: #ea4f21; color: white; padding: 10px; }
      th[scope="row"] { background: #fff3ef; color: #ea4f21; padding: 10px; }
      td { padding: 10px; border: 1px solid #e2e8f0; }
    </style>
  </head>
  <body>
    <table aria-label="Monthly sales data for 2024">
      <caption>Monthly Sales — Techbase Academy 2024</caption>
      <thead>
        <tr>
          <th scope="col">Month</th>
          <th scope="col">Students</th>
          <th scope="col">Revenue (₦)</th>
        </tr>
      </thead>
      <tbody>
        <tr>
          <th scope="row">January</th>
          <td>24</td><td>120,000</td>
        </tr>
        <tr>
          <th scope="row">February</th>
          <td>31</td><td>155,000</td>
        </tr>
      </tbody>
    </table>
  </body>
</html>
✏️ Your Task

Add a <caption> to your timetable table. Add scope="col" to your column headers and scope="row" to any row headers. This makes your table work correctly with screen readers — great accessibility practice!

🏗️ Build It!
My Data Table

Build a fully styled data table with header, body, striped rows, hover effect, and a caption.

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>My Data Table</title>
    <style>
      body { font-family: Arial, sans-serif; padding: 30px;
             max-width: 800px; margin: 0 auto; background: #f8fafc; }
      h1 { color: #0f172a; }
      table { width: 100%; border-collapse: collapse; margin-top: 20px;
              box-shadow: 0 2px 8px rgba(0,0,0,.08); border-radius: 12px;
              overflow: hidden; }
      caption { font-weight: bold; color: #ea4f21; font-size: 1.05rem;
                text-align: left; margin-bottom: 8px; }
      th { background: #ea4f21; color: white; padding: 14px 16px;
           text-align: left; font-size: 14px; letter-spacing: .03em; }
      td { padding: 12px 16px; color: #334155; font-size: 14px;
           border-bottom: 1px solid #e2e8f0; }
      tr:nth-child(even) td { background: #f8fafc; }
      tr:hover td { background: #fff3ef; }
      .badge { display: inline-block; padding: 2px 10px; border-radius: 100px;
               font-size: 12px; font-weight: bold; }
      .a { background: #dcfce7; color: #166534; }
      .b { background: #dbeafe; color: #1e40af; }
    </style>
  </head>
  <body>
    <h1>Student Results Table</h1>
    <table>
      <caption>Term 1 Examination Results — [Your Class]</caption>
      <thead>
        <tr>
          <th scope="col">Name</th>
          <th scope="col">Maths</th>
          <th scope="col">English</th>
          <th scope="col">Science</th>
          <th scope="col">Grade</th>
        </tr>
      </thead>
      <tbody>
        <tr>
          <th scope="row">Amina Bello</th>
          <td>95</td><td>88</td><td>92</td>
          <td><span class="badge a">A</span></td>
        </tr>
        <tr>
          <th scope="row">Tunde Awoyemi</th>
          <td>82</td><td>90</td><td>85</td>
          <td><span class="badge b">B+</span></td>
        </tr>
        <!-- Add at least 4 more students! -->
      </tbody>
    </table>
  </body>
</html>
