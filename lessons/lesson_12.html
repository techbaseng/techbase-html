HTML CSS — Styling Introduction

Learn three ways to add CSS to your pages: inline, internal, and external. In this lesson you will work through 2 phases. Complete each phase task before clicking Next Phase.

Phase 1
Inline vs Internal CSS
💡 Concept

There are three ways to add CSS to HTML. Inline uses the style attribute directly on an element — good for quick one-off changes. Internal uses a <style> block inside the <head> — good for styling a single page. External links a separate .css file using <link rel="stylesheet" href="style.css"> inside the <head> — the best practice for real projects!

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Internal CSS</title>
    <!-- Internal CSS goes here in the head -->
    <style>
      body {
        background-color: #f8fafc;
        font-family: Arial, sans-serif;
      }
      h1 {
        color: #ea4f21;
        text-align: center;
      }
      p {
        color: #334155;
        font-size: 16px;
        line-height: 1.7;
      }
    </style>
  </head>
  <body>
    <h1>Styled with Internal CSS</h1>
    <p>All paragraphs on this page get the same style
       automatically because we put the rules in &lt;style&gt;.</p>
    <p>No need to repeat the style on each tag!</p>
  </body>
</html>

Phase 2
External CSS — The Best Way
💡 Concept

An external CSS file keeps all your styles in one place. When you have 10 pages and want to change a colour, you only change it once in the CSS file and all pages update instantly. Link the CSS file in the <head> with: <link rel="stylesheet" href="style.css">. The CSS file is just a text file with .css extension — no HTML tags inside it, just CSS rules.

index.html + style.css 
<!-- index.html -->
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>External CSS</title>
    <link rel="stylesheet" href="style.css">
  </head>
  <body>
    <h1>Styled by an External File</h1>
    <p class="intro">This paragraph has the intro class.</p>
    <p>This is a normal paragraph.</p>
  </body>
</html>

/* style.css — separate file! */
body {
  background-color: #f8fafc;
  font-family: Arial, sans-serif;
  max-width: 800px;
  margin: 0 auto;
  padding: 20px;
}
h1 { color: #ea4f21; }
p { color: #334155; line-height: 1.8; }
.intro { font-weight: bold; font-size: 18px; }

🏗️ Build It!
My Three-Way Styled Page

Build a page that uses EXTERNAL CSS. Create index.html and style.css side by side in the same folder.

starter.html — copy this into a new file! 
<!DOCTYPE html>
<!-- index.html -->
<html lang="en">
  <head>
    <title>My Styled Page</title>
    <link rel="stylesheet" href="style.css">
  </head>
  <body>
    <h1>My Beautifully Styled Page</h1>
    <p class="intro">This is the introduction paragraph — styled with a class!</p>

    <h2>Section One</h2>
    <p>This paragraph is styled by the external CSS file.</p>
    <p>Every paragraph on the page automatically gets the same style.</p>

    <h2>Section Two</h2>
    <p>Change the color in <strong>style.css</strong> and
       ALL paragraphs update at once. That is the power of external CSS!</p>
  </body>
</html>

/* ─── PASTE THIS INTO style.css (separate file) ─── */
body {
  background-color: #f8fafc;
  font-family: Arial, sans-serif;
  max-width: 750px;
  margin: 0 auto;
  padding: 30px;
}
h1 { color: #ea4f21; text-align: center; }
h2 { color: #0284c7; border-bottom: 2px solid #e2e8f0; padding-bottom: 6px; }
p  { color: #334155; line-height: 1.8; font-size: 16px; }
.intro { font-weight: bold; font-size: 18px; color: #0f172a; }
