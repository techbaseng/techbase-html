Phase 1
Semantic Layout Elements
💡 Concept

HTML5 introduced semantic layout elements that describe the PURPOSE of each section. <header> — the top section (logo, site name, tagline). <nav> — navigation links. <main> — the main unique content of the page (only ONE per page). <article> — a self-contained piece of content (blog post, news story). <aside> — sidebar content. <footer> — the bottom section (copyright, links). Using these instead of plain <div> helps search engines and screen readers understand your page.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Semantic Layout</title>
    <style>
      * { box-sizing: border-box; }
      body { margin: 0; font-family: Arial, sans-serif; }
      header { background: #ea4f21; color: white; padding: 20px 30px; }
      nav    { background: #0f172a; padding: 12px 30px; }
      nav a  { color: white; text-decoration: none; margin-right: 20px; }
      .page-wrap { display: flex; max-width: 960px; margin: 0 auto; gap: 24px; padding: 24px; }
      main   { flex: 3; }
      aside  { flex: 1; background: #f8fafc; padding: 20px; border-radius: 10px; }
      footer { background: #0f172a; color: #94a3b8; text-align: center; padding: 20px; }
    </style>
  </head>
  <body>
    <header>
      <h1>My Website</h1>
      <p>A tagline goes here</p>
    </header>

    <nav>
      <a href="#home">Home</a>
      <a href="#about">About</a>
      <a href="#contact">Contact</a>
    </nav>

    <div class="page-wrap">
      <main>
        <h2>Main Content</h2>
        <p>This is the main article area — the most important content.</p>
      </main>

      <aside>
        <h3>Sidebar</h3>
        <p>Extra info, ads, or related links.</p>
      </aside>
    </div>

    <footer>
      <p>© 2025 My Website | Ibadan, Nigeria</p>
    </footer>
  </body>
</html>

Phase 2
Article and Section
💡 Concept

<article> wraps content that makes sense on its own — if you copied it to another website, it would still make sense (blog post, news article, forum post). <section> groups related content within a page — it should always have a heading. The rule: <article> can contain <section>s, and <section>s can contain <article>s. Both help search engines and screen readers understand the structure.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Article and Section</title>
    <style>
      article {
        background: white; border: 1.5px solid #e2e8f0;
        border-radius: 12px; padding: 24px; margin: 20px 0;
      }
      article header h2 { color: #ea4f21; margin: 0 0 8px; }
      article header p  { color: #64748b; font-size: 13px; margin: 0 0 16px; }
      section { margin-top: 20px; padding-top: 16px; border-top: 1px solid #f1f5f9; }
      section h3 { color: #0284c7; }
    </style>
  </head>
  <body>
    <main>
      <article>
        <header>
          <h2>My First Blog Post</h2>
          <p>Published: 1 January 2025 | By: Techbase Student</p>
        </header>

        <p>This is the introduction to my blog post...</p>

        <section>
          <h3>Section 1 — What I Learned</h3>
          <p>Today I learned about semantic HTML elements.</p>
        </section>

        <section>
          <h3>Section 2 — What's Next</h3>
          <p>Next I will learn about CSS layouts.</p>
        </section>
      </article>
    </main>
  </body>
</html>
✏️ Your Task

Write a short blog post using <article>. Inside it, create three <section>s: introduction, main points, and conclusion. Give each section an <h3> heading. Notice how this is much more meaningful than using only <div> everywhere.

Phase 3
CSS Flexbox for Layout
💡 Concept

The most modern way to create multi-column layouts is CSS Flexbox. Add display: flex to a container and its children line up in a row by default. flex: 2 on one child and flex: 1 on another makes the first one twice as wide. gap adds spacing between them. flex-wrap: wrap lets items wrap to a new row on small screens. Flexbox is much better than old-style table or float layouts!

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Flexbox Layout</title>
    <style>
      * { box-sizing: border-box; }
      body { margin: 0; font-family: Arial; }
      header { background: #ea4f21; color: white; padding: 20px 30px; }
      .flex-wrap {
        display: flex; gap: 24px;
        padding: 24px; max-width: 1000px; margin: 0 auto;
      }
      main  { flex: 3; background: white; padding: 20px; border-radius: 12px; }
      aside { flex: 1; background: #f8fafc; padding: 16px; border-radius: 12px; }
      footer { background: #0f172a; color: white; text-align: center; padding: 20px; }

      /* Make it stack on small screens */
      @media (max-width: 600px) {
        .flex-wrap { flex-direction: column; }
      }
    </style>
  </head>
  <body>
    <header><h1>Flex Layout Demo</h1></header>

    <div class="flex-wrap">
      <main>
        <h2>Main (flex: 3)</h2>
        <p>This takes up 3/4 of the available width because flex: 3.</p>
      </main>
      <aside>
        <h3>Aside (flex: 1)</h3>
        <p>Takes up 1/4 — flex: 1.</p>
      </aside>
    </div>

    <footer><p>Footer always at the bottom</p></footer>
  </body>
</html>
✏️ Your Task

Add a @media (max-width: 600px) rule that changes your flex layout from row to column on small screens. Resize your browser window to phone width — the sidebar should now appear BELOW the main content instead of beside it.

🏗️ Build It!
My Full-Layout Page

Build a complete page using header, nav, main, aside, article, section, and footer with flexbox.

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Tech Blog | [Your Name]</title>
    <style>
      * { box-sizing: border-box; margin: 0; padding: 0; }
      body { font-family: Arial, sans-serif; background: #f1f5f9; color: #0f172a; }

      header {
        background: linear-gradient(135deg, #ea4f21, #c23d15);
        color: white; padding: 28px 30px;
      }
      header h1 { font-size: 1.8rem; }
      header p  { opacity: .8; font-size: .9rem; margin-top: 4px; }

      nav {
        background: #0f172a; padding: 0 30px;
        display: flex; gap: 0;
      }
      nav a {
        color: rgba(255,255,255,.7); text-decoration: none;
        padding: 14px 20px; font-size: 14px; font-weight: 600;
        display: inline-block; transition: color .2s;
      }
      nav a:hover { color: white; background: rgba(255,255,255,.05); }

      .page-wrap {
        display: flex; gap: 24px;
        max-width: 1000px; margin: 28px auto; padding: 0 24px;
      }

      main  { flex: 3; }
      aside { flex: 1; }

      article {
        background: white; border-radius: 14px;
        padding: 28px; margin-bottom: 20px;
        box-shadow: 0 2px 8px rgba(0,0,0,.06);
      }
      article h2 { color: #ea4f21; margin-bottom: 6px; }
      .meta { color: #94a3b8; font-size: 13px; margin-bottom: 16px; }

      section { margin-top: 20px; padding-top: 16px; border-top: 1px solid #f1f5f9; }
      section h3 { color: #0284c7; margin-bottom: 8px; }

      .widget {
        background: white; border-radius: 14px;
        padding: 20px; margin-bottom: 16px;
        box-shadow: 0 2px 8px rgba(0,0,0,.06);
      }
      .widget h4 { color: #ea4f21; margin-bottom: 12px; }
      .widget ul { list-style: none; padding: 0; }
      .widget li { padding: 6px 0; border-bottom: 1px solid #f1f5f9;
                   font-size: 14px; color: #475569; }

      footer {
        background: #0f172a; color: rgba(255,255,255,.5);
        text-align: center; padding: 24px; font-size: 13px;
      }
      footer a { color: rgba(255,255,255,.7); text-decoration: none; }

      @media (max-width: 640px) {
        .page-wrap { flex-direction: column; }
      }
    </style>
  </head>
  <body>

    <header>
      <h1>📝 [Your Name]'s Tech Blog</h1>
      <p>Documenting my HTML journey at Techbase Academy, Ibadan</p>
    </header>

    <nav>
      <a href="#home">Home</a>
      <a href="#posts">Posts</a>
      <a href="#about">About</a>
      <a href="#contact">Contact</a>
    </nav>

    <div class="page-wrap">
      <main id="posts">
        <article>
          <h2>What I Learned in HTML Lesson 25</h2>
          <p class="meta">📅 [Today's Date] · ✍️ [Your Name] · 🏷️ HTML, Layout</p>

          <p>Today I learned about semantic HTML layout elements...</p>

          <section>
            <h3>🔷 Semantic vs Non-Semantic</h3>
            <p>Using header, nav, main, aside and footer instead of divs everywhere
               helps search engines AND screen readers understand the page structure.</p>
          </section>

          <section>
            <h3>🔷 Flexbox Layout</h3>
            <p>I used display: flex to create a two-column layout with a main content
               area and a sidebar. On mobile it stacks into a single column.</p>
          </section>

          <section>
            <h3>🔷 What's Next</h3>
            <p>In Lesson 26 I will learn about responsive web design and media queries!</p>
          </section>
        </article>

        <article>
          <h2>My HTML Journey So Far</h2>
