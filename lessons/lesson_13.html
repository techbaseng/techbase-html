Phase 1
Basic Links and the href Attribute
💡 Concept

Links are created with the <a> (anchor) tag. The href attribute tells the browser WHERE to go. You can link to: an external website (href="https://..."), another page in your project (href="about.html"), or a section on the same page (href="#section-id"). By default, a link opens in the same tab. Add target="_blank" to open in a new tab.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head><title>Links</title></head>
  <body>
    <h1>Link Examples</h1>

    <!-- External link, same tab -->
    <p><a href="https://techbasengr.com.ng">Techbase Website</a></p>

    <!-- External link, new tab -->
    <p><a href="https://w3schools.com" target="_blank">
      W3Schools (opens in new tab)
    </a></p>

    <!-- Link to another local page -->
    <p><a href="about.html">About Me Page</a></p>

    <!-- Jump to a section on the same page -->
    <p><a href="#footer">Jump to footer</a></p>

    <br><br><br><br><br><br>

    <footer id="footer">
      <hr>
      <p>This is the footer!</p>
    </footer>
  </body>
</html>

Phase 2
Link Colours and Styling
💡 Concept

By default, links are blue (unvisited), purple (visited), and red (active/clicking). You can change these with CSS. Links also show a hand cursor when you hover. The best practice is to make links visually obvious — use colour, underline, or a button style so users know they are clickable. You can also use an image as a link by wrapping <img> inside <a>.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Styled Links</title>
    <style>
      a { color: #ea4f21; text-decoration: none; font-weight: bold; }
      a:hover { text-decoration: underline; color: #c23d15; }

      .btn-link {
        display: inline-block;
        background: #ea4f21;
        color: white;
        padding: 10px 20px;
        border-radius: 8px;
        text-decoration: none;
        font-weight: bold;
      }
      .btn-link:hover { background: #c23d15; color: white; }
    </style>
  </head>
  <body>
    <h1>Styled Links</h1>
    <p><a href="https://techbasengr.com.ng">Normal styled link</a></p>

    <p>
      <a href="https://techbasengr.com.ng" class="btn-link">
        Button Link →
      </a>
    </p>

    <!-- Image as a link -->
    <a href="https://techbasengr.com.ng">
      <img src="https://via.placeholder.com/200x80"
           alt="Click to visit Techbase">
    </a>
  </body>
</html>

Phase 3
Bookmark Links and Email Links
💡 Concept

A bookmark link uses an id on a destination element and links to #that-id — clicking scrolls the page straight there. An email link uses href="mailto:someone@example.com" — clicking opens the user's email program. A phone link uses href="tel:+2348012345678" — on mobile it offers to call that number!

index.html 
<!DOCTYPE html>
<html lang="en">
  <head><title>Special Links</title></head>
  <body>
    <nav>
      <a href="#intro">Introduction</a> |
      <a href="#skills">Skills</a> |
      <a href="#contact">Contact</a>
    </nav>

    <h2 id="intro">Introduction</h2>
    <p>Welcome to my page! Use the nav links above to jump around.</p>
    <br><br><br>

    <h2 id="skills">Skills</h2>
    <p>HTML, CSS, JavaScript — learning every day!</p>
    <br><br><br>

    <h2 id="contact">Contact</h2>
    <p>Email: <a href="mailto:me@example.com">me@example.com</a></p>
    <p>Phone: <a href="tel:+2348000000000">+234 800 000 0000</a></p>
  </body>
</html>

🏗️ Build It!
My Link Collection

Build a multi-page mini-site: index.html links to about.html and contact.html, all linked together.

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>My Website — Home</title>
    <style>
      body { font-family: Arial, sans-serif; max-width:750px;
             margin:0 auto; padding:30px; background:#f8fafc; }
      nav { background:#ea4f21; padding:14px 20px; border-radius:10px;
            margin-bottom:24px; }
      nav a { color:white; text-decoration:none; font-weight:bold;
              margin-right:20px; }
      nav a:hover { text-decoration:underline; }
      .btn { display:inline-block; background:#ea4f21; color:white;
             padding:10px 20px; border-radius:8px; text-decoration:none;
             font-weight:bold; margin-top:10px; }
      .btn:hover { background:#c23d15; }
    </style>
  </head>
  <body>
    <nav>
      <a href="index.html">Home</a>
      <a href="about.html">About</a>
      <a href="contact.html">Contact</a>
    </nav>

    <h1>Welcome to My Website!</h1>
    <p>This is the home page. Navigate using the links above.</p>

    <h2>Quick Links</h2>
    <p><a href="about.html" class="btn">Learn About Me →</a></p>
    <p><a href="contact.html" class="btn">Get In Touch →</a></p>

    <h2>Jump to Section</h2>
    <a href="#footer">Skip to footer</a>

    <br><br><br>
    <footer id="footer">
      <hr>
      <p>Contact: <a href="mailto:you@example.com">you@example.com</a></p>
      <p>Phone: <a href="tel:+2348000000000">+234 800 000 000</a></p>
    </footer>
  </body>
</html>
