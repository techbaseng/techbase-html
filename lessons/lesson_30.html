Phase 1
Character Sets and UTF-8
💡 Concept

A character set maps numbers to characters. ASCII handles only 128 English characters. UTF-8 handles over 1.1 million characters — every language, symbol and emoji on Earth. Always declare <meta charset="UTF-8"> as the FIRST tag inside <head>. All modern browsers default to UTF-8 but it is still best practice to declare it explicitly.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>Character Sets</title>
  </head>
  <body>
    <h1>Characters from Around the World</h1>
    <p>English: Hello, World!</p>
    <p>Yoruba: Ẹ káàárọ̀ (Good morning)</p>
    <p>Hausa: Sannu (Hello)</p>
    <p>Arabic: مرحباً | Chinese: 你好</p>
    <p>Emoji: 🚀 🎓 💡 ✅ 🌍</p>
    <p>Maths: π ≈ 3.14 | √2 ≈ 1.41 | ∞</p>
    <p>Currency: $ £ € ¥ ₦ ₹</p>
    <p>Without UTF-8, many of these show as ??? or boxes!</p>
  </body>
</html>

Phase 2
URL Encoding
💡 Concept

URL encoding converts special characters in web addresses to a safe format. Spaces → %20, # → %23, & → %26. You see this in search URLs. The browser does encoding automatically, but knowing it helps you read and debug web addresses.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>URL Encoding</title>
    <style>
      table { border-collapse:collapse; width:100%; }
      th { background:#ea4f21; color:white; padding:10px; }
      td { padding:8px 12px; border-bottom:1px solid #e2e8f0; font-family:monospace; }
    </style>
  </head>
  <body>
    <h1>URL Encoding</h1>
    <p>Searching Google for "Techbase Ibadan" gives URL:</p>
    <p><code>https://www.google.com/search?q=Techbase%20Ibadan</code></p>
    <p>The space became <strong>%20</strong>!</p>
    <h2>Common Encodings</h2>
    <table>
      <tr><th>Character</th><th>Encoded</th><th>Example</th></tr>
      <tr><td>Space</td><td>%20</td><td>hello%20world</td></tr>
      <tr><td>#</td><td>%23</td><td>section%23one</td></tr>
      <tr><td>&amp;</td><td>%26</td><td>name%26age</td></tr>
      <tr><td>=</td><td>%3D</td><td>name%3Dtunde</td></tr>
      <tr><td>?</td><td>%3F</td><td>search%3Fquery</td></tr>
    </table>
  </body>
</html>

🏗️ Build It!
My Encoding Reference Page

Build a charset and URL encoding reference page showing multilingual content and encoded URL examples.

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Encoding Reference — Lesson 30</title>
    <style>
      * { box-sizing:border-box; }
      body { font-family:Arial,sans-serif; max-width:800px;
             margin:0 auto; padding:30px; background:#f8fafc; }
      h1 { color:#ea4f21; }
      h2 { color:#0f172a; margin-top:30px; border-bottom:2px solid #e2e8f0; padding-bottom:6px; }
      code { background:#f1f5f9; padding:2px 6px; border-radius:4px;
             font-family:monospace; color:#7c3aed; }
      table { border-collapse:collapse; width:100%; margin:16px 0; }
      th { background:#ea4f21; color:white; padding:10px; text-align:left; }
      td { padding:9px 12px; border-bottom:1px solid #e2e8f0; }
      tr:nth-child(even) td { background:#f8fafc; }
      .lang-box { background:white; border:1.5px solid #e2e8f0;
                  border-radius:12px; padding:20px; margin:16px 0; }
      .lang-box p { margin:4px 0; font-size:15px; }
    </style>
  </head>
  <body>
    <h1>Encoding Reference Sheet</h1>
    <h2>🌍 UTF-8 — Every Language</h2>
    <div class="lang-box">
      <p>🇳🇬 Yoruba: <strong>Ẹ káàárọ̀</strong></p>
      <p>🇳🇬 Hausa: <strong>Sannu</strong></p>
      <p>🇳🇬 Igbo: <strong>Nnọọ</strong></p>
      <p>🌐 Arabic: <strong>مرحباً</strong></p>
      <p>🧮 Maths: π ≈ 3.14 | √2 | ∞ | ≠ | ≤</p>
      <p>💰 Currency: ₦ ¥ £ € $</p>
      <p>😊 Emoji: 🚀 🎓 💡 ✅ 🏆</p>
    </div>
    <p>All rendered correctly because of: <code>&lt;meta charset="UTF-8"&gt;</code></p>
    <h2>🔗 URL Encoding Table</h2>
    <table>
      <thead><tr><th>Character</th><th>Encoded</th><th>When</th></tr></thead>
      <tbody>
        <tr><td>Space</td><td><code>%20</code></td><td>Search queries</td></tr>
        <tr><td>#</td><td><code>%23</code></td><td>Hash in query strings</td></tr>
        <tr><td>&amp;</td><td><code>%26</code></td><td>Multiple parameters</td></tr>
        <tr><td>=</td><td><code>%3D</code></td><td>Query values</td></tr>
        <tr><td>?</td><td><code>%3F</code></td><td>Nested queries</td></tr>
        <tr><td>/</td><td><code>%2F</code></td><td>Slashes in data</td></tr>
      </tbody>
    </table>
    <h2>🔍 Real URL Example</h2>
    <p>Google search for "Techbase Ibadan HTML":</p>
    <p><code>https://www.google.com/search?q=Techbase%20Ibadan%20HTML</code></p>
  </body>
</html>
