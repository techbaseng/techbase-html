HTML File Paths

Phase 1
Absolute vs Relative Paths
💡 Concept

An absolute path is the full URL or full file path from the very root: https://example.com/images/photo.jpg. A relative path is relative to the current file's location. images/photo.jpg — means 'look in an images folder next to this file'. ../images/photo.jpg — means 'go UP one folder then into images'. Relative paths are best for local projects because they still work when you move the whole folder.

index.html 
Folder structure for this example:
my-project/
  index.html        ← you are here
  about.html
  images/
    logo.png
    banner.jpg
  pages/
    contact.html

In index.html:

<!-- Relative paths from index.html -->
<img src="images/logo.png" alt="Logo">
<img src="images/banner.jpg" alt="Banner">
<a href="about.html">About</a>
<a href="pages/contact.html">Contact</a>

In pages/contact.html (one level deeper):

<!-- Must go UP one level with ../ -->
<img src="../images/logo.png" alt="Logo">
<a href="../index.html">Home</a>
✏️ Your Task

Create this exact folder structure on your computer. Put a real image file in the images/ folder. Write the correct src paths in each HTML file. Test that images load in both index.html and pages/contact.html.

Phase 2
Common Path Patterns
💡 Concept

There are four path patterns you need to know: (1) file.html — same folder. (2) folder/file.html — go into a subfolder. (3) ../file.html — go up one folder. (4) /file.html — from the website root (absolute on the same server). The most common mistake beginners make is getting the path wrong when their file is in a subfolder — always count your folder levels!

index.html 
<!-- ✅ CORRECT examples -->

<!-- Image in same folder as HTML file -->
<img src="photo.jpg" alt="Photo">

<!-- Image in a subfolder -->
<img src="images/photo.jpg" alt="Photo">

<!-- Image TWO folders up, then into assets -->
<img src="../../assets/photo.jpg" alt="Photo">

<!-- Absolute URL (from the web) -->
<img src="https://example.com/photo.jpg" alt="Photo">

<!-- ❌ WRONG — Windows backslash doesn't work in HTML -->
<img src="images\photo.jpg" alt="Photo">

<!-- ❌ WRONG — spaces in file names cause problems -->
<img src="my photo.jpg" alt="Photo">
<!-- Use hyphens instead: my-photo.jpg -->
✏️ Your Task

Check all your previous project files. Find any images or links that use absolute paths. Change them to relative paths. Then rename any image files that have spaces in their names to use hyphens instead (e.g., my photo.jpg → my-photo.jpg).

Try the task first, then click to continue!

🏗️ Build It!
My Multi-File Project

Build a 3-page mini-website (index, about, contact) with a shared images folder and correct relative paths.

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Home — My Website</title>
    <link rel="stylesheet" href="css/style.css">
  </head>
  <body>

    <nav>
      <a href="index.html">Home</a>
      <a href="about.html">About</a>
      <a href="contact.html">Contact</a>
    </nav>

    <h1>Home Page</h1>
    <img src="images/banner.jpg" alt="Banner image" width="600">
    <p>This project uses RELATIVE paths to link pages and images.</p>

  </body>
</html>

<!-- ─────────────────────────────────────── -->
