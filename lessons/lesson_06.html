Phase 1
The Paragraph Element
💡 Concept

The <p> tag creates a paragraph. Browsers automatically add some space above and below each paragraph. An important rule: the browser ignores extra spaces and line breaks that you type inside your HTML code — it only adds spaces where you use HTML tags. So if you press Enter 10 times inside a <p> tag, the browser will treat all that text as ONE line.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head><title>Paragraphs</title></head>
  <body>

    <h1>My Story</h1>

    <p>This is the first paragraph. Browsers add space
    above and below each paragraph automatically.</p>

    <p>This is the second paragraph. Even if I write
    lots of extra        spaces    here, the browser
    will only show one space between words.</p>

    <p>Each new &lt;p&gt; tag starts a new paragraph.</p>

  </body>
</html>

Phase 2
Line Breaks and Horizontal Rules
💡 Concept

To force a new line WITHOUT starting a new paragraph, use <br> (break). This is useful for poems and addresses. To draw a horizontal line across the page, use <hr>. Both are empty elements — no closing tag. Also, if you want to show a space in a special way, use &nbsp; (a non-breaking space — a special HTML code called an entity).

index.html 
<!DOCTYPE html>
<html lang="en">
  <head><title>Breaks and Rules</title></head>
  <body>

    <h1>My Address</h1>
    <p>
      Techbase Academy<br>
      123 Coding Street<br>
      Ibadan, Oyo State<br>
      Nigeria
    </p>

    <hr>

    <h2>A Short Poem</h2>
    <p>
      Roses are red,<br>
      Violets are blue,<br>
      HTML is fun,<br>
      And I love it too!
    </p>

    <hr>

    <p>Price:&nbsp;&nbsp;&nbsp;₦5,000</p>

  </body>
</html>
✏️ Your Task

Write a short poem or address using <br> tags to control where lines break. Use <hr> between sections. Notice that <br> moves to a new line but stays INSIDE the same paragraph.

🏗️ Build It!
My Story Page

Write a 3-paragraph story using proper paragraphs, line breaks, and horizontal rules to separate sections.

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>My Story</title>
  </head>
  <body>

    <h1>The Day I Learned to Code</h1>

    <h2>How It Started</h2>
    <p>
      Write your first paragraph here. Tell the reader how your
      coding journey began. Use this whole paragraph to set the scene.
    </p>

    <hr>

    <h2>The Challenge</h2>
    <p>
      Write what was difficult at first.<br>
      You can use line breaks inside paragraphs<br>
      to control exactly where each line ends —<br>
      great for dramatic effect in a story!
    </p>

    <hr>

    <h2>What I Discovered</h2>
    <p>
      Write your final paragraph here. What did you learn?
      How do you feel about coding now?
    </p>

    <hr>
    <p>Written by [Your Name] | Techbase HTML Course — Lesson 06</p>

  </body>
</html>
