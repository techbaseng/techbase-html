Phase 1
The class Attribute
💡 Concept

The class attribute lets you give one or more HTML elements the same name, then style them ALL at once with CSS using a dot selector (.classname). For example, if five paragraphs all have class="intro", writing .intro { color: blue; } colours all five at once. A class name can be used on ANY element — a <p>, a <div>, an <h2>, anything.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Classes</title>
    <style>
      /* Target any element with class="note" */
      .note {
        background: #fef3c7;
        border-left: 4px solid #d97706;
        padding: 10px 14px;
        border-radius: 0 8px 8px 0;
        margin: 12px 0;
      }
      .highlight { background: #dbeafe; font-weight: bold; }
      .danger    { color: #dc2626; font-weight: bold; }
    </style>
  </head>
  <body>
    <h1>Using Classes</h1>

    <p class="note">This is a note — styled with the .note class.</p>
    <div class="note">This div also uses the .note class!</div>
    <h3 class="note">Even this h3 uses .note!</h3>

    <p>This word is <span class="highlight">highlighted</span> using a class.</p>
    <p>This is a <span class="danger">danger warning!</span></p>
  </body>
</html>

Phase 2
Multiple Classes on One Element
💡 Concept

An HTML element can have more than one class! Separate class names with a space: class="card featured". The element gets ALL styles from ALL its classes. This is very powerful — you can have a base class (card) for the general structure, and a modifier class (featured) for the special version.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Multiple Classes</title>
    <style>
      .card {
        border: 1.5px solid #e2e8f0;
        border-radius: 12px;
        padding: 18px;
        margin: 12px 0;
        background: white;
      }
      .featured {
        border-color: #ea4f21;
        border-width: 2px;
        box-shadow: 0 4px 14px rgba(234,79,33,.2);
      }
      .muted { color: #94a3b8; }
      .large { font-size: 1.2rem; }
    </style>
  </head>
  <body style="background:#f1f5f9; padding:20px; font-family:Arial;">
    <h1>Card Examples</h1>

    <!-- Base card only -->
    <div class="card">Normal card</div>

    <!-- Card + featured — gets BOTH styles -->
    <div class="card featured">
      <strong>⭐ Featured card</strong> — has card + featured classes
    </div>

    <!-- Text with two classes -->
    <p class="muted large">Large muted text — two classes on one element!</p>
  </body>
</html>

🏗️ Build It!
My Class-Styled Cards Page

Build a product card grid using CSS classes. Each card shares a base class but has its own colour modifier class.

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>My Product Cards</title>
    <style>
      * { box-sizing: border-box; }
      body { font-family: Arial, sans-serif; background: #f1f5f9;
             padding: 30px; }
      h1 { text-align: center; color: #0f172a; }

      /* Base card class — all cards share this */
      .card {
        background: white; border-radius: 14px;
        padding: 24px; margin: 12px;
        box-shadow: 0 2px 8px rgba(0,0,0,.06);
        display: inline-block; width: 220px;
        vertical-align: top;
      }
      .card h3 { margin-top: 0; font-size: 1rem; }
      .card .price { font-size: 1.4rem; font-weight: bold; }

      /* Modifier classes — each card can add one */
      .red   { border-top: 4px solid #ea4f21; }
      .red   .price { color: #ea4f21; }

      .blue  { border-top: 4px solid #0284c7; }
      .blue  .price { color: #0284c7; }

      .green { border-top: 4px solid #10b981; }
      .green .price { color: #10b981; }

      .purple{ border-top: 4px solid #7c3aed; }
      .purple .price { color: #7c3aed; }

      .badge { font-size: 11px; font-weight: bold; padding: 3px 8px;
               border-radius: 100px; display: inline-block; margin-bottom: 8px; }
      .badge-new { background: #dcfce7; color: #166534; }
      .badge-hot { background: #fee2e2; color: #991b1b; }
    </style>
  </head>
  <body>
    <h1>Course Catalogue</h1>
    <div style="text-align:center;">

      <div class="card red">
        <span class="badge badge-new">NEW</span>
        <h3>HTML Basics</h3>
        <p class="price">Free</p>
        <p>Learn the structure of every website.</p>
      </div>

      <div class="card blue">
        <span class="badge badge-hot">🔥 HOT</span>
        <h3>CSS Mastery</h3>
        <p class="price">₦5,000</p>
        <p>Make beautiful pages with CSS.</p>
      </div>

      <div class="card green">
        <h3>JavaScript</h3>
        <p class="price">₦8,000</p>
        <p>Make your pages interactive!</p>
      </div>

      <div class="card purple">
        <h3>Python</h3>
        <p class="price">₦7,500</p>
        <p>Build apps and automate tasks.</p>
      </div>

    </div>
  </body>
</html>
