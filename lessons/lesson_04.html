Phase 1
What Are Attributes?
💡 Concept

Attributes provide extra information about an HTML element. They always go in the opening tag and come in name/value pairs like name="value". For example, <img src="cat.jpg"> — src is the attribute name and "cat.jpg" is the value. Always use double quotes around the value!

index.html 
<!DOCTYPE html>
<html>
  <head><title>Attributes</title></head>
  <body>

    <!-- href attribute tells the link where to go -->
    <a href="https://techbasengr.com.ng">Techbase Website</a>

    <br><br>

    <!-- src and alt attributes on an image -->
    <img src="https://via.placeholder.com/250x150"
         alt="A sample image"
         width="250"
         height="150">

  </body>
</html>

Phase 2
The style Attribute
💡 Concept

The style attribute lets you add CSS directly inside an HTML tag. This is called inline styling. The value is CSS written as property: value;. You can add colours, fonts, sizes and more this way. Later you'll learn a better way to do this, but inline styles are great for quick testing!

index.html 
<!DOCTYPE html>
<html>
  <head><title>Style Attribute</title></head>
  <body>

    <h1 style="color: blue;">Blue Heading</h1>

    <p style="color: green; font-size: 20px;">
      This paragraph is green and bigger!
    </p>

    <p style="background-color: yellow; padding: 10px;">
      This paragraph has a yellow background.
    </p>

    <h2 style="font-family: Arial; text-align: center;">
      Centred Arial Heading
    </h2>

  </body>
</html>
✏️ Your Task

Phase 3
The lang and title Attributes
💡 Concept

The lang attribute on the <html> tag tells search engines and screen readers what language the page is in. Always set it to lang="en" for English. The title attribute can go on almost any element — when you hover over it, a small tooltip appears. These are called global attributes because they work on any HTML element.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Global Attributes</title>
  </head>
  <body>

    <h1 title="This is the main page title">Hover over me!</h1>

    <p title="This paragraph has a tooltip">
      Move your mouse over this text slowly...
    </p>

    <abbr title="HyperText Markup Language">HTML</abbr>
    is the language of the web.

  </body>
</html>
✏️ Your Task

Add lang="en" to your <html> tag. Then add title="..." attributes to three different elements on your page. Hover over them in the browser to see the tooltips appear.

Try the task first, then click to continue!

🏗️ Build It!
My Attributes Playground

Build a styled page that uses href, src, alt, style, target, width, height and title attributes.

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Attributes in Action</title>
  </head>
  <body>

    <h1 style="color: #ea4f21; text-align: center;">
      HTML Attributes Playground
    </h1>

    <h2>Links with Attributes</h2>
    <p>
      <a href="https://techbasengr.com.ng"
         target="_blank"
         title="Click to open Techbase website">
        Visit Techbase Academy
      </a>
    </p>

    <h2>Image with Attributes</h2>
    <img src="https://via.placeholder.com/350x200"
         alt="My favourite image"
         width="350"
         title="This is my image">

    <h2>Styled Paragraph</h2>
    <p style="background-color: #fff3ef; padding: 15px; border-left: 4px solid #ea4f21;">
      This paragraph uses <strong>style attributes</strong> to look great!
    </p>

    <p>Made with ❤️ by [Your Name]</p>

  </body>
</html>
