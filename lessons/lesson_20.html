Phase 1
The id Attribute — Unique Identity
💡 Concept

The id attribute gives an element a unique name on the page. Unlike class (which can be reused on many elements), each id must be used only once per page. In CSS you target it with a hash: #header. In HTML you can link directly to an id with href="#header". In JavaScript you can find the element with document.getElementById("header").

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Id Attribute</title>
    <style>
      /* Target an id with # in CSS */
      #header {
        background: #ea4f21;
        color: white;
        padding: 20px;
        text-align: center;
      }
      #main-content {
        max-width: 700px;
        margin: 0 auto;
        padding: 20px;
      }
      #footer {
        background: #0f172a;
        color: #94a3b8;
        text-align: center;
        padding: 16px;
        margin-top: 40px;
      }
    </style>
  </head>
  <body>
    <div id="header">
      <h1>My Page Header</h1>
      <p>Styled with #header CSS rule</p>
    </div>

    <div id="main-content">
      <h2>Main Content</h2>
      <p>Styled with #main-content CSS rule.</p>
      <a href="#footer">Jump to footer</a>
    </div>

    <div id="footer">
      <p>Footer — linked here from above!</p>
    </div>
  </body>
</html>

Phase 2
Id for Navigation and JavaScript
💡 Concept

The id attribute is used very heavily in single-page apps — where you click a menu item and the page scrolls to that section without loading a new page. It is also how JavaScript changes page content — document.getElementById('myId').style.color = 'red' finds the element by its id and changes its style. You will use this a LOT when you learn JavaScript!

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Id and JavaScript</title>
    <style>
      #demo-box {
        background: #f0f9ff;
        border: 2px solid #0284c7;
        border-radius: 12px;
        padding: 20px;
        margin: 20px 0;
        text-align: center;
        font-size: 1.1rem;
        transition: background 0.3s;
      }
    </style>
  </head>
  <body>
    <h1>Id and JavaScript</h1>

    <div id="demo-box">
      Click a button to change me!
    </div>

    <!-- Buttons that use JavaScript + id to change the box -->
    <button onclick="document.getElementById('demo-box').style.background='#fff3ef'">
      Orange tint
    </button>
    <button onclick="document.getElementById('demo-box').style.background='#dcfce7'">
      Green tint
    </button>
    <button onclick="document.getElementById('demo-box').innerHTML='<strong>You changed my content!</strong>'">
      Change text
    </button>
  </body>
</html>

🏗️ Build It!
My Single-Page App

Build a single-page portfolio with a sticky nav that uses id-based jump links to all sections.

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>[Your Name] — Portfolio</title>
    <style>
      * { box-sizing: border-box; scroll-behavior: smooth; }
      body { font-family: Arial, sans-serif; margin: 0;
             background: #f8fafc; color: #0f172a; }
      /* Sticky nav */
      #nav {
        position: sticky; top: 0; z-index: 100;
        background: #ea4f21; padding: 14px 24px;
        display: flex; gap: 20px; align-items: center;
        box-shadow: 0 2px 8px rgba(234,79,33,.3);
      }
      #nav a { color: white; text-decoration: none;
               font-weight: bold; font-size: 14px; }
      #nav a:hover { text-decoration: underline; }
      /* Sections */
      section { padding: 60px 30px; max-width: 800px; margin: 0 auto; }
      section h2 { font-size: 1.8rem; color: #ea4f21;
                   border-bottom: 3px solid #ea4f21;
                   padding-bottom: 8px; margin-bottom: 20px; }
      #hero {
        background: linear-gradient(135deg, #fff3ef, #f8fafc);
        text-align: center; padding: 80px 30px;
      }
      #hero h1 { font-size: 2.5rem; color: #ea4f21; }
      #contact a { color: #ea4f21; font-weight: bold; }
    </style>
  </head>
  <body>

    <!-- STICKY NAVIGATION using id links -->
    <div id="nav">
      <strong style="font-size:16px;">⚡ [Your Name]</strong>
      <a href="#about">About</a>
      <a href="#skills">Skills</a>
      <a href="#projects">Projects</a>
      <a href="#contact">Contact</a>
    </div>

    <!-- HERO with id for jumping back to top -->
    <div id="hero">
      <h1>Hi, I'm [Your Name]!</h1>
      <p>HTML learner · Future web developer · Techbase Academy</p>
    </div>

    <!-- ABOUT -->
    <section id="about">
      <h2>About Me</h2>
      <p>Write about yourself here — where you're from, what you love,
         and why you're learning to code.</p>
    </section>

    <!-- SKILLS -->
    <section id="skills">
      <h2>My Skills</h2>
      <p>✅ HTML &nbsp;|&nbsp; 🔄 CSS (learning) &nbsp;|&nbsp;
         🔜 JavaScript (coming soon)</p>
    </section>

    <!-- PROJECTS -->
    <section id="projects">
      <h2>My Projects</h2>
      <p>I have built these pages during my Techbase HTML course:</p>
      <ul>
        <li>Lesson 01 — My First Web Page</li>
        <li>Lesson 07 — My Styled Info Card</li>
        <li>Lesson 14 — My Photo Gallery</li>
      </ul>
    </section>

    <!-- CONTACT -->
    <section id="contact">
      <h2>Contact</h2>
      <p>Email: <a href="mailto:you@example.com">you@example.com</a></p>
      <p><a href="#hero">↑ Back to top</a></p>
    </section>

  </body>
</html>
