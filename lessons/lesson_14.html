Phase 1
The img Tag and alt Attribute
💡 Concept

Images use the <img> tag with two required attributes: src (the image path or URL) and alt (a text description). The alt text is vital — it shows if the image fails to load AND is read aloud by screen readers for people with visual impairments. Always write a meaningful alt description! The width and height attributes control the display size (in pixels).

index.html 
<!DOCTYPE html>
<html lang="en">
  <head><title>Images</title></head>
  <body>
    <h1>Image Examples</h1>

    <!-- Image from the web -->
    <img src="https://via.placeholder.com/400x250"
         alt="A grey placeholder rectangle"
         width="400">

    <!-- Image from local file (put photo.jpg in same folder) -->
    <!-- <img src="photo.jpg" alt="My photo" width="300"> -->

    <!-- No width — image shows at full original size -->
    <img src="https://via.placeholder.com/200x200/ea4f21/fff?text=HTML"
         alt="Orange square with HTML text">
  </body>
</html>

Phase 2
Image as Link and CSS Styling
💡 Concept

You can make an image clickable by wrapping it in an <a> tag. CSS can style images too — use border-radius: 50% to make a circle, border to add a frame, and object-fit: cover to fill a fixed-size box without distorting the image.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Image Styles</title>
    <style>
      .round { border-radius: 50%; width:150px; height:150px; object-fit:cover; }
      .framed { border: 4px solid #ea4f21; border-radius: 8px; }
      .card-img { width:100%; height:180px; object-fit:cover; border-radius:12px 12px 0 0; }
    </style>
  </head>
  <body>
    <!-- Circular profile picture -->
    <img src="https://via.placeholder.com/150" alt="Profile photo" class="round">

    <!-- Framed image -->
    <img src="https://via.placeholder.com/250x150" alt="Landscape" class="framed">

    <!-- Clickable image link -->
    <a href="https://techbasengr.com.ng">
      <img src="https://via.placeholder.com/200x80/ea4f21/fff?text=TECHBASE"
           alt="Visit Techbase Academy">
    </a>
  </body>
</html>
✏️ Your Task

Phase 3
Figure and Figcaption
💡 Concept

Use <figure> and <figcaption> to group an image with its caption. This is the semantic way to add images — it tells the browser (and search engines) that the caption belongs to that specific image. The <figure> element can also hold code, charts, or any content that is referenced from the main text.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Figure and Figcaption</title>
    <style>
      figure {
        display: inline-block;
        margin: 16px;
        border: 1px solid #e2e8f0;
        border-radius: 12px;
        overflow: hidden;
        width: 250px;
      }
      figure img { width: 100%; display: block; }
      figcaption {
        padding: 10px;
        font-size: 13px;
        color: #64748b;
        background: #f8fafc;
        text-align: center;
      }
    </style>
  </head>
  <body>
    <h1>My Photo Gallery</h1>

    <figure>
      <img src="https://via.placeholder.com/250x160" alt="Sunset photo">
      <figcaption>A beautiful sunset in Ibadan, 2024.</figcaption>
    </figure>

    <figure>
      <img src="https://via.placeholder.com/250x160/0284c7/fff" alt="Sky photo">
      <figcaption>Clear blue sky in the morning.</figcaption>
    </figure>
  </body>
</html>
✏️ Your Task

🏗️ Build It!
My Photo Gallery

Build a styled photo gallery page with 6 figure/figcaption cards, round images, and styled captions.

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>My Photo Gallery</title>
    <style>
      body { font-family: Arial, sans-serif; background:#f1f5f9;
             padding:30px; max-width:900px; margin:0 auto; }
      h1 { text-align:center; color:#0f172a; margin-bottom:8px; }
      .subtitle { text-align:center; color:#64748b; margin-bottom:30px; }
      .gallery { display:flex; flex-wrap:wrap; gap:20px; justify-content:center; }
      figure { width:260px; background:white; border-radius:14px;
               overflow:hidden; box-shadow:0 2px 8px rgba(0,0,0,0.08);
               margin:0; }
      figure img { width:100%; height:170px; object-fit:cover; display:block; }
      figcaption { padding:12px; font-size:13px; color:#475569;
                   text-align:center; font-style:italic; }
      .profile { border-radius:50%; width:80px; height:80px;
                 object-fit:cover; display:block; margin:0 auto 12px; }
    </style>
  </head>
  <body>
    <img src="https://via.placeholder.com/80/ea4f21/fff?text=ME"
         alt="My profile picture" class="profile">
    <h1>My Photo Gallery</h1>
    <p class="subtitle">A collection of my favourite images</p>

    <div class="gallery">
      <figure>
        <img src="https://via.placeholder.com/260x170/ea4f21/fff?text=Photo+1"
             alt="Photo 1 description">
        <figcaption>Write a caption for this photo here.</figcaption>
      </figure>

      <figure>
        <img src="https://via.placeholder.com/260x170/0284c7/fff?text=Photo+2"
             alt="Photo 2 description">
        <figcaption>Write a caption for this photo here.</figcaption>
      </figure>

      <figure>
        <img src="https://via.placeholder.com/260x170/10b981/fff?text=Photo+3"
             alt="Photo 3 description">
        <figcaption>Write a caption for this photo here.</figcaption>
      </figure>

      <!-- Add 3 more figures below! -->
    </div>
  </body>
</html>
