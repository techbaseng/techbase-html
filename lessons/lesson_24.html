Phase 1
Charset and Viewport Meta Tags
💡 Concept

The <head> section holds metadata — information about the page that is NOT displayed to visitors. The most important meta tags: <meta charset="UTF-8"> — ensures all characters (including ₦, é, 中, أ) display correctly. <meta name="viewport" content="width=device-width, initial-scale=1.0"> — makes the page look correct on mobile phones (without this, mobile browsers zoom out and show a tiny version).

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <!-- Character set — always put this FIRST in head -->
    <meta charset="UTF-8">

    <!-- Viewport — makes the page mobile-friendly -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <!-- Page title shown in browser tab and Google results -->
    <title>My Perfect Head Section | Techbase</title>
  </head>
  <body>
    <h1>Check the head section of this page!</h1>
    <p>Currency: ₦1,000</p>
    <p>French: café, naïve, résumé</p>
    <p>Emoji: 🚀 😊 ✅</p>
    <p>All render correctly because of UTF-8 charset!</p>
  </body>
</html>
✏️ Your Task

Open this page on your phone or shrink the browser window to phone width. With the viewport meta tag, the text should be readable. Without it, open a page you made earlier — does it look zoomed out on a narrow window? Add the viewport meta tag and see the difference!

Phase 2
Description, Keywords and Author Meta
💡 Concept

Three more important meta tags: description — a 150-character summary shown in Google search results (write it carefully — it is like your page's advert!). keywords — less important today but still used by some search engines. author — your name as the page creator. The <base> tag sets a default URL for all relative paths on the page (useful for sites with many subfolders).

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <!-- SEO meta tags -->
    <meta name="description"
          content="Learn HTML at Techbase Academy in Ibadan. Free STEM coding lessons for students aged 8-18. Build real websites from lesson one!">

    <meta name="keywords"
          content="HTML tutorial, coding for kids, STEM education, Ibadan, Techbase">

    <meta name="author" content="Babatunde Awoyemi, Techbase Academy">

    <!-- Open Graph (for social media sharing) -->
    <meta property="og:title" content="Techbase HTML Course">
    <meta property="og:description" content="Free HTML lessons for students">
    <meta property="og:image" content="https://techbasengr.com.ng/logo.png">

    <title>Techbase HTML Course — Free STEM Lessons in Ibadan</title>
  </head>
  <body>
    <h1>Well-Optimised Page</h1>
    <p>Right-click and 'View Page Source' to see all the meta tags.</p>
  </body>
</html>

Phase 3
Link and Script Tags in Head
💡 Concept

The <link> tag in the head connects external resources: rel="stylesheet" links a CSS file, rel="icon" links a favicon, rel="preconnect" speeds up Google Fonts loading. The <style> tag holds internal CSS. The <script> tag links JavaScript — usually placed at the END of the body (not in head) so the page loads faster, but sometimes in head with defer.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Head Resources</title>

    <!-- External CSS file -->
    <link rel="stylesheet" href="style.css">

    <!-- Favicon -->
    <link rel="icon" type="image/png" href="favicon.png">

    <!-- Google Fonts (preconnect first for speed, then the font) -->
    <link rel="preconnect" href="https://fonts.googleapis.com">
    <link href="https://fonts.googleapis.com/css2?family=Poppins:wght@400;700&display=swap"
          rel="stylesheet">

    <!-- Internal CSS (only for styles unique to THIS page) -->
    <style>
      body { font-family: 'Poppins', sans-serif; }
    </style>
  </head>
  <body>
    <h1>Perfect Head Section!</h1>
    <p>This page uses an external CSS file AND a Google Font.</p>

    <!-- JavaScript goes at the END of body for faster loading -->
    <script src="script.js" defer></script>
  </body>
</html>
✏️ Your Task

Add a Google Font to one of your projects. Go to fonts.google.com, pick a font you like, click 'Get Font' then 'Get embed code' and copy the two <link> tags into your <head>. Then use font-family: 'Your Font Name', sans-serif; in your CSS.

🏗️ Build It!
My Well-Headed Page

Build a page with a perfect head section: charset, viewport, description, author, favicon, and a Google Font.

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <head>
    <!-- ===== ESSENTIAL ===== -->
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <!-- ===== SEO ===== -->
    <title>[Your Page Topic] — [Your Name] | Techbase Academy</title>
    <meta name="description"
          content="[Write a compelling 150-char description of your page here. Use an action verb!]">
    <meta name="author" content="[Your Name], Techbase Academy Ibadan">
    <meta name="keywords" content="[topic], html, techbase, ibadan, coding">

    <!-- ===== SOCIAL SHARING ===== -->
    <meta property="og:title" content="[Your Page Topic]">
    <meta property="og:description" content="[Same as description above]">

    <!-- ===== FAVICON ===== -->
    <link rel="icon" type="image/png" href="favicon.png">

    <!-- ===== GOOGLE FONTS ===== -->
    <link rel="preconnect" href="https://fonts.googleapis.com">
    <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
    <link href="https://fonts.googleapis.com/css2?family=Poppins:wght@400;600;700&display=swap"
          rel="stylesheet">

    <!-- ===== STYLES ===== -->
    <style>
      body {
        font-family: 'Poppins', sans-serif;
        max-width: 750px; margin: 0 auto;
        padding: 30px; background: #f8fafc;
        color: #0f172a;

    </style>
  </head>
  <body>
