Phase 1
Inline Styles — Colour and Font
💡 Concept

The style attribute goes inside the opening tag. You write CSS properties and values separated by a colon, and each rule ends with a semicolon. The most common properties are: color (text colour), background-color (background), font-family (font), font-size (text size). For colours you can use names like red or hex codes like #ff0000.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head><title>Inline Styles</title></head>
  <body>

    <h1 style="color: #ea4f21;">Orange Heading</h1>

    <p style="color: green; font-size: 18px;">
      This text is green and 18 pixels tall.
    </p>

    <p style="font-family: Georgia, serif; color: navy;">
      This text uses the Georgia font in navy blue.
    </p>

    <p style="background-color: #fffbe6; padding: 12px;">
      This paragraph has a light yellow background with padding.
    </p>

  </body>
</html>
✏️ Your Task

Give your <h1> a colour using a hex code (try #0284c7 for blue). Give your paragraph a background-color and some padding (padding adds space inside the element). Notice how much easier it is to read with spacing!

Phase 2
Text Alignment and Font Size
💡 Concept

You can centre text, right-align it, or left-align it using the text-align property. Font sizes can be set with px (pixels — fixed size), em (relative to the parent element's size), or %. Common values: 14px for small, 16px for normal body text, 24px for large, 48px for really big display text.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head><title>Text Alignment</title></head>
  <body>

    <h1 style="text-align: center; font-size: 48px; color: #ea4f21;">
      Centred Big Title
    </h1>

    <p style="text-align: center; font-size: 18px; color: #555;">
      This paragraph is also centred.
    </p>

    <p style="text-align: left;">This is left-aligned (the default).</p>

    <p style="text-align: right; color: #ea4f21;">
      This is right-aligned!
    </p>

  </body>
</html>
✏️ Your Task

Centre your <h1> and make it 48px. Then make one paragraph left-aligned and another right-aligned. Experiment with different font sizes — what looks best for a heading vs body text?

Phase 3
Background and Border Styles
💡 Concept

You can set the background-color of the whole page by styling the <body> tag. The border property adds a border around an element — it needs three values: thickness, style (solid, dashed, dotted) and colour. For example: border: 2px solid #ea4f21;. Combined with padding and border-radius, you can make great-looking cards!

index.html 
<!DOCTYPE html>
<html lang="en">
  <head><title>Cards with Borders</title></head>
  <body style="background-color: #f8fafc; font-family: Arial, sans-serif;">

    <h1 style="text-align: center; color: #0f172a;">My Info Cards</h1>

    <div style="border: 2px solid #ea4f21; border-radius: 12px;
                padding: 20px; margin: 20px; background-color: white;">
      <h2 style="color: #ea4f21;">Card 1</h2>
      <p>This is a card with an orange border and rounded corners.</p>
    </div>

    <div style="border: 2px solid #0284c7; border-radius: 12px;
                padding: 20px; margin: 20px; background-color: #f0f9ff;">
      <h2 style="color: #0284c7;">Card 2</h2>
      <p>This card has a blue border and a light blue background.</p>
    </div>

  </body>
</html>
✏️ Your Task

Create three info cards using <div> tags, each with a different border colour, border-radius, padding and background. You can use margin to add space between the cards.

🏗️ Build It!
My Styled Info Card

Build a stylish personal information card using inline CSS: colours, fonts, borders, padding and alignment.

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>My Info Card</title>
  </head>
  <body style="background-color: #f1f5f9;
               font-family: Arial, sans-serif;
               display: flex; justify-content: center;
               padding: 40px;">

    <div style="background-color: white;
                border: 2px solid #ea4f21;
                border-radius: 16px;
                padding: 30px;
                max-width: 400px;
                width: 100%;">

      <h1 style="color: #ea4f21;
                 text-align: center;
                 font-size: 28px;">
        [Your Name]
      </h1>

      <p style="text-align: center;
                color: #64748b;
                font-size: 14px;">
        HTML Learner | Techbase Academy
      </p>

      <hr style="border: 1px solid #e2e8f0; margin: 16px 0;">

      <p><strong>Age:</strong> [Your Age]</p>
      <p><strong>City:</strong> [Your City]</p>
      <p><strong>Favourite Subject:</strong> [Subject]</p>
      <p><strong>Hobby:</strong> [Hobby]</p>

      <div style="background-color: #fff3ef;
                  border-left: 4px solid #ea4f21;
                  padding: 12px;
                  border-radius: 4px;
                  margin-top: 16px;">
        <p style="color: #92400e; font-size: 14px;">
          💡 <strong>Fun Fact:</strong> [Write a fun fact about yourself!]
        </p>
      </div>

    </div>
  </body>
</html>
