Phase 1
HTML5 Video
💡 Concept

The <video> element adds a video player. Key attributes: controls (shows play/pause), autoplay muted (auto-starts — muted required by most browsers), loop, poster="thumb.jpg" (thumbnail before play). Provide multiple sources using <source> tags for browser compatibility — MP4 is the most supported format.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head><title>HTML Video</title></head>
  <body>
    <h1>HTML5 Video</h1>
    <video width="560" controls
           style="border-radius:12px; display:block;">
      <source src="video.mp4"  type="video/mp4">
      <source src="video.webm" type="video/webm">
      Your browser does not support the video element.
    </video>
    <p>Replace src with a real video file path!</p>
    <h2>Auto-play (muted) background video</h2>
    <video width="560" autoplay muted loop
           style="border-radius:12px; display:block; margin-top:16px;">
      <source src="background.mp4" type="video/mp4">
    </video>
  </body>
</html>
✏️ Your Task

Download any short MP4 video, place it in your project folder, add it with <video controls>. Set width="100%". Try adding poster="thumbnail.jpg" to show a thumbnail before play.

Phase 2
HTML5 Audio
💡 Concept

The <audio> element works like video but for sound. Attributes: controls, autoplay, loop, muted. Supported formats: MP3 (most common), OGG, WAV. You can also control audio with JavaScript: audio.play(), audio.pause(), audio.volume = 0.5.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head><title>HTML Audio</title></head>
  <body>
    <h1>HTML5 Audio</h1>
    <audio controls style="width:100%;">
      <source src="music.mp3" type="audio/mpeg">
      <source src="music.ogg" type="audio/ogg">
      Your browser does not support the audio element.
    </audio>
    <h2>JavaScript Controls</h2>
    <audio id="myAudio">
      <source src="music.mp3" type="audio/mpeg">
    </audio>
    <button onclick="myAudio.play()">▶️ Play</button>
    <button onclick="myAudio.pause()">⏸️ Pause</button>
    <button onclick="myAudio.volume=0.2">🔉 Low</button>
    <button onclick="myAudio.volume=1">🔊 Full</button>
    <br><br>
    Volume slider:
    <input type="range" min="0" max="1" step="0.1"
           oninput="myAudio.volume=this.value">
    <script>const myAudio=document.getElementById('myAudio');</script>
  </body>
</html>
✏️ Your Task

Add an audio player with custom play/pause buttons. Add a volume slider using <input type="range"> and wire it up with oninput="myAudio.volume=this.value".

Phase 3
Responsive YouTube Embeds
💡 Concept

YouTube embeds are the easiest way to add video — you don't host anything! Click Share → Embed on YouTube, copy the <iframe>. Make it responsive with the 56.25% padding-bottom trick (keeps 16:9 ratio at any width). Always add title on iframes for screen readers, and loading="lazy" for performance.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>YouTube Embed</title>
    <style>
      .video-wrap {
        position:relative; padding-bottom:56.25%;
        height:0; overflow:hidden;
        border-radius:14px; box-shadow:0 4px 20px rgba(0,0,0,.12);
      }
      .video-wrap iframe {
        position:absolute; top:0; left:0;
        width:100%; height:100%; border:0;
      }
    </style>
  </head>
  <body style="font-family:Arial; padding:30px; background:#f8fafc;">
    <h1>Responsive YouTube Embed</h1>
    <div class="video-wrap">
      <iframe
        src="https://www.youtube.com/embed/dQw4w9WgXcQ"
        title="My chosen tutorial video"
        allow="accelerometer; autoplay; clipboard-write; encrypted-media"
        allowfullscreen loading="lazy">
      </iframe>
    </div>
    <p style="margin-top:16px; font-size:14px; color:#64748b;">
      Replace the video ID in the src URL with any YouTube video's ID!
    </p>
  </body>
</html>
✏️ Your Task

Make your YouTube embed fully responsive. Replace the video ID with a tutorial you actually like. Add loading="lazy". Resize the browser — the 16:9 ratio should be maintained at every width.
