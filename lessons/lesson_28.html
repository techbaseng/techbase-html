Phase 1
What Makes an Element Semantic?
💡 Concept

A semantic HTML element has a name that describes its meaning. <p> means 'paragraph' — semantic. <div> means nothing — just a box. Semantic tags tell browsers, search engines and screen readers WHAT the content is. Key semantic elements: <header>, <nav>, <main>, <footer>, <article>, <section>, <aside>.

index.html 
<!-- ❌ Non-semantic — meaningless divs everywhere -->
<div class="header"><div class="title">My Site</div></div>
<div class="content">
  <div class="post"><div class="post-title">Article</div></div>
</div>

<!-- ✅ Semantic — every tag describes its purpose -->
<!DOCTYPE html>
<html lang="en">
  <head><title>Semantic HTML</title></head>
  <body>
    <header><h1>My Site</h1></header>
    <nav><a href="#home">Home</a></nav>
    <main>
      <article>
        <h2>My Article</h2>
        <p>Content here.</p>
      </article>
    </main>
    <footer><p>© 2025</p></footer>
  </body>
</html>

Phase 2
time, mark, details and figure
💡 Concept

<time datetime="2025-01-01"> marks a date machines can read. <mark> highlights important text. <details> and <summary> create a native accordion that opens/closes — no JavaScript needed! <figure> and <figcaption> group media with its caption.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head><title>Semantic Elements</title></head>
  <body>
    <p>Published: <time datetime="2025-01-15">January 15, 2025</time></p>
    <p>Search results for: <mark>HTML semantic elements</mark></p>

    <details>
      <summary>What is semantic HTML? (click to expand)</summary>
      <p>Semantic HTML uses tags that describe the meaning of content
         rather than just its appearance. Better SEO, better accessibility.</p>
    </details>

    <details>
      <summary>Why does it matter?</summary>
      <p>Search engines rank semantic pages higher. Screen readers
         navigate semantic pages easily. Code is easier to maintain.</p>
    </details>

    <figure>
      <img src="https://via.placeholder.com/400x200" alt="Semantic HTML diagram">
      <figcaption>Figure 1: Semantic HTML structure</figcaption>
    </figure>
  </body>
</html>

Phase 3
address, cite and best practices
💡 Concept

<address> marks contact info for the author. <cite> marks the title of a creative work. Semantic rules: (1) Never use headings just to make text big — use CSS font-size instead. (2) Never use <br> for spacing — use CSS margin. (3) Every image needs meaningful alt text. (4) Every form input needs a <label>. (5) Use the most specific tag available.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Semantic Best Practices</title>
    <style>
      article { max-width:700px; margin:0 auto; padding:30px; }
      article > header { border-bottom:2px solid #e2e8f0; margin-bottom:24px; }
    </style>
  </head>
  <body>
    <main>
      <article>
        <header>
          <h1>The Power of Semantic HTML</h1>
          <p>By <strong>Tunde</strong> |
             <time datetime="2025-01-15">15 January 2025</time></p>
        </header>
        <p>As <cite>Ethan Marcotte</cite> wrote in
           <cite>Responsive Web Design</cite>,
           semantic HTML is the foundation of a good website.</p>
        <p>The <mark>most important rule</mark> is to always use
           the most meaningful tag available.</p>
        <footer>
          <address>
            Written at Techbase Academy<br>
            Ibadan, Oyo State, Nigeria
          </address>
        </footer>
      </article>
    </main>
  </body>
</html>

🏗️ Build It!
My Semantic News Page

Build a news article page using ONLY semantic HTML — header, nav, main, article, section, aside, footer.

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Techbase News — Semantic HTML</title>
    <style>
      * { box-sizing:border-box; }
      body { font-family:Georgia,serif; background:#f8fafc; margin:0; }
      header { background:#ea4f21; color:white; padding:20px 30px; }
      header h1 { font-family:Arial; font-size:1.6rem; margin:0; }
      nav { background:#0f172a; padding:10px 30px; }
      nav a { color:rgba(255,255,255,.7); text-decoration:none;
              font-family:Arial; font-size:13px; margin-right:16px; font-weight:600; }
      .page { display:flex; gap:24px; max-width:1000px;
              margin:28px auto; padding:0 20px; }
      main { flex:3; }
      aside { flex:1; }
      article { background:white; border-radius:14px;
                padding:28px; box-shadow:0 2px 8px rgba(0,0,0,.06); }
      article > header { border-bottom:1px solid #e2e8f0; margin-bottom:20px; }
      article > header h2 { font-size:1.5rem; color:#0f172a; margin:0 0 8px; }
      .byline { font-family:Arial; font-size:13px; color:#94a3b8; }
      article p { line-height:1.85; color:#334155; }
      article > footer { border-top:1px solid #e2e8f0; margin-top:20px; padding-top:14px; }
      figure { margin:20px 0; }
      figure img { width:100%; border-radius:10px; }
      figcaption { font-size:12px; color:#94a3b8; font-family:Arial; margin-top:6px; }
      details { background:#f8fafc; border:1px solid #e2e8f0;
                border-radius:8px; padding:12px 16px; margin:16px 0; }
      summary { font-family:Arial; font-weight:bold; color:#ea4f21; cursor:pointer; }
      .widget { background:white; border-radius:14px; padding:20px;
                box-shadow:0 2px 8px rgba(0,0,0,.06); margin-bottom:16px; }
      .widget h4 { font-family:Arial; color:#ea4f21; margin:0 0 12px; }
      footer { background:#0f172a; color:rgba(255,255,255,.5);
               font-family:Arial; text-align:center; padding:20px;
               font-size:13px; margin-top:30px; }
      @media (max-width:640px) { .page { flex-direction:column; } }
    </style>
  </head>
  <body>
    <header><h1>📰 Techbase News</h1></header>
    <nav><a href="#">Tech</a><a href="#">Coding</a><a href="#">Education</a></nav>
    <div class="page">
      <main>
        <article>
          <header>
            <h2>Student Builds First Website Using Semantic HTML</h2>
            <p class="byline">By <strong>[Your Name]</strong> ·
               <time datetime="2025-01-15">January 15, 2025</time></p>
          </header>
          <figure>
            <img src="https://via.placeholder.com/660x280/ea4f21/fff?text=Techbase+News"
                 alt="Student building a website at Techbase Academy">
            <figcaption>A Techbase student builds their first semantic HTML page.</figcaption>
          </figure>
          <p>A student at <mark>Techbase Academy in Ibadan</mark> has
             completed Lesson 28 using only semantic HTML elements.</p>
          <section>
            <h3>Why Semantic HTML Matters</h3>
            <p>Semantic elements help search engines, screen readers,
               and other developers understand the page structure instantly.</p>
          </section>
          <details>
            <summary>What is a semantic element? (FAQ)</summary>
            <p>A semantic element describes its purpose. &lt;article&gt; means
               "this is an article." A &lt;div&gt; means nothing — just a box.</p>
          </details>
          <footer>
            <address>
              Written by [Your Name]<br>
              Techbase Academy, Ibadan, Nigeria
            </address>

        </article>
      </main>
