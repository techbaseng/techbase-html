Phase 1
The Button Element
💡 Concept

The <button> element creates a clickable button. Unlike a link (<a>), a button is designed to trigger an action on the page rather than navigate somewhere. You can put text, icons or images inside a button. Buttons have a type attribute: type="button" (general purpose), type="submit" (submits a form), and type="reset" (resets a form). Always specify the type!

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Buttons</title>
    <style>
      .btn {
        padding: 10px 22px; border: none; border-radius: 8px;
        font-size: 15px; font-weight: bold; cursor: pointer;
        margin: 6px; transition: opacity .2s;
      }
      .btn:hover { opacity: .85; }
      .btn-orange { background: #ea4f21; color: white; }
      .btn-blue   { background: #0284c7; color: white; }
      .btn-outline {
        background: transparent; color: #ea4f21;
        border: 2px solid #ea4f21;
      }
    </style>
  </head>
  <body>
    <h1>Button Styles</h1>

    <button type="button" class="btn btn-orange">Orange Button</button>
    <button type="button" class="btn btn-blue">Blue Button</button>
    <button type="button" class="btn btn-outline">Outline Button</button>
    <button type="button" class="btn btn-orange" disabled>Disabled</button>
  </body>
</html>

Phase 2
Buttons with onclick and JavaScript
💡 Concept

Buttons become truly powerful when paired with the onclick attribute, which runs JavaScript when the button is clicked. You can show alerts, change text, toggle colours, count clicks, and more — all from a simple button click. This is the gateway between HTML and JavaScript!

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Interactive Buttons</title>
    <style>
      .btn { padding:10px 22px; border:none; border-radius:8px;
             font-size:15px; font-weight:bold; cursor:pointer;
             background:#ea4f21; color:white; margin:6px; }
      .btn:hover { background: #c23d15; }
      #output {
        margin-top: 20px; padding: 16px;
        background: #f8fafc; border: 1.5px solid #e2e8f0;
        border-radius: 10px; font-size: 1rem;
        min-height: 50px;
      }
    </style>
  </head>
  <body>
    <h1>Interactive Buttons</h1>

    <button class="btn"
            onclick="document.getElementById('output').textContent='Hello World!'">
      Say Hello
    </button>

    <button class="btn" style="background:#0284c7;"
            onclick="document.getElementById('output').style.background='#dbeafe'">
      Change Colour
    </button>

    <button class="btn" style="background:#10b981;"
            onclick="document.getElementById('output').textContent=new Date().toLocaleTimeString()">
      Show Time
    </button>

    <div id="output">Click a button above to see something happen!</div>
  </body>
</html>

My Interactive Button Board

Build an interactive button board with 6 buttons that each do something different when clicked.

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>My Button Board</title>
    <style>
      body { font-family: Arial, sans-serif; background: #f1f5f9;
             padding: 30px; max-width: 700px; margin: 0 auto; }
      h1 { color: #0f172a; text-align: center; }
      .board { display: flex; flex-wrap: wrap; gap: 12px;
               justify-content: center; margin: 24px 0; }
      .btn { padding: 12px 24px; border: none; border-radius: 10px;
             font-size: 15px; font-weight: bold; cursor: pointer;
             transition: transform .15s, box-shadow .15s; }
      .btn:hover { transform: translateY(-2px); box-shadow: 0 4px 12px rgba(0,0,0,.15); }
      .btn:active { transform: translateY(0); }
      #display {
        background: white; border: 2px solid #e2e8f0; border-radius: 14px;
        padding: 24px; text-align: center; font-size: 1.1rem;
        min-height: 80px; color: #334155; margin-top: 10px;
        transition: background .3s;
      }
    </style>
  </head>
  <body>
    <h1>🎮 My Button Board</h1>

    <div class="board">
      <button class="btn" style="background:#ea4f21;color:white;"
        onclick="display.textContent='👋 Hello from HTML!'">
        Say Hello
      </button>

      <button class="btn" style="background:#0284c7;color:white;"
        onclick="display.style.background='#dbeafe'; display.textContent='💙 Blue!'">
        Go Blue
      </button>

      <button class="btn" style="background:#10b981;color:white;"
        onclick="display.style.background='#dcfce7'; display.textContent='💚 Green!'">
        Go Green
      </button>

      <button class="btn" style="background:#7c3aed;color:white;"
        onclick="display.innerHTML='<strong>⏰ ' + new Date().toLocaleTimeString() + '</strong>'">
        Show Time
      </button>

      <button class="btn" style="background:#d97706;color:white;"
        onclick="count++; display.textContent='🖱️ Clicks: ' + count">
        Count Clicks
      </button>

      <button class="btn" style="background:#0f172a;color:white;"
        onclick="display.textContent=''; display.style.background='white'; count=0;">
        Reset
      </button>
    </div>

    <div id="display">Click any button to see the magic! ✨</div>

    <script>
      const display = document.getElementById('display');
      let count = 0;
    </script>
  </body>
</html>
