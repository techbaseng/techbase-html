Phase 1
Unordered and Ordered Lists
💡 Concept

An unordered list (<ul>) shows items with bullet points — use it when the order doesn't matter (e.g., ingredients). An ordered list (<ol>) shows items with numbers — use it when order matters (e.g., steps). Both use <li> (list item) tags for each item. You can change the bullet style with CSS list-style-type and the number type with the type attribute on <ol>.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head><title>Lists</title></head>
  <body>

    <h2>My Favourite Foods (unordered — order doesn't matter)</h2>
    <ul>
      <li>Jollof rice</li>
      <li>Suya</li>
      <li>Puff puff</li>
      <li>Fried plantain</li>
    </ul>

    <h2>How to Make Jollof Rice (ordered — steps matter!)</h2>
    <ol>
      <li>Blend tomatoes and peppers</li>
      <li>Fry the blended mixture in oil</li>
      <li>Add rice and water</li>
      <li>Cook on low heat for 30 minutes</li>
    </ol>

    <!-- Ordered list with letters instead of numbers -->
    <ol type="A">
      <li>Option A</li>
      <li>Option B</li>
      <li>Option C</li>
    </ol>

  </body>
</html>

Phase 2
Nested Lists and Description Lists
💡 Concept

You can put a list inside a list item to create a nested list — great for outlines and menus. A description list (<dl>) pairs terms with their definitions. Use <dt> for the term and <dd> for the description. You can also style list bullets completely with CSS using list-style: none and custom bullet shapes.

index.html 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Nested Lists</title>
    <style>
      /* Custom styled list */
      ul.custom { list-style: none; padding: 0; }
      ul.custom li { padding: 6px 0; padding-left: 24px; position: relative; }
      ul.custom li::before {
        content: "🔹";
        position: absolute; left: 0;
      }
    </style>
  </head>
  <body>

    <h2>Nested List — Tech Topics</h2>
    <ul>
      <li>Frontend
        <ul>
          <li>HTML</li>
          <li>CSS</li>
          <li>JavaScript</li>
        </ul>
      </li>
      <li>Backend
        <ul>
          <li>Python</li>
          <li>Node.js</li>
        </ul>
      </li>
    </ul>

    <h2>Description List — HTML Terms</h2>
    <dl>
      <dt><strong>HTML</strong></dt>
      <dd>HyperText Markup Language — the structure of web pages</dd>

      <dt><strong>Tag</strong></dt>
      <dd>An HTML keyword in angle brackets, like &lt;p&gt;</dd>
    </dl>

    <h2>Custom Styled List</h2>
    <ul class="custom">
      <li>Learn HTML first</li>
      <li>Then learn CSS</li>
      <li>Then JavaScript</li>
    </ul>

  </body>
</html>

🏗️ Build It!
My Lists Page

Build a styled 'My Top Lists' page with a custom-styled ul, a recipe ol, a nested list, and a dl glossary.

starter.html — copy this into a new file! 
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>My Top Lists</title>
    <style>
      body { font-family: Arial, sans-serif; max-width:700px;
             margin:0 auto; padding:30px; background:#f8fafc; }
      h1 { color: #ea4f21; }
      h2 { color: #0f172a; margin-top: 30px; border-bottom: 2px solid #e2e8f0;
           padding-bottom: 6px; }
      ul.fancy { list-style: none; padding: 0; }
      ul.fancy li { padding: 8px 0 8px 30px; border-bottom: 1px solid #e2e8f0;
                    position: relative; }
      ul.fancy li::before { content: "⭐"; position: absolute; left: 0; }
      ol.recipe li { margin-bottom: 10px; color: #334155; }
      dl dt { font-weight: bold; color: #ea4f21; margin-top: 12px; }
      dl dd { margin-left: 20px; color: #475569; }
    </style>
  </head>
  <body>

    <h1>My Top Lists 📋</h1>

    <h2>⭐ My Top 5 Favourite Things</h2>
    <ul class="fancy">
      <li>[Favourite thing 1]</li>
      <li>[Favourite thing 2]</li>
      <li>[Favourite thing 3]</li>
      <li>[Favourite thing 4]</li>
      <li>[Favourite thing 5]</li>
    </ul>

    <h2>🍳 Recipe: How to Make [Your Favourite Meal]</h2>
    <ol class="recipe">
      <li>[Step 1]</li>
      <li>[Step 2]</li>
      <li>[Step 3]</li>
      <li>[Step 4]</li>
      <li>[Step 5 — Enjoy!]</li>
    </ol>

    <h2>🌍 My Tech Learning Path</h2>
    <ul>
      <li>Web Development
        <ul>
          <li>HTML ✅ (learning now!)</li>
          <li>CSS (coming next)</li>
          <li>JavaScript (after CSS)</li>
        </ul>
      </li>
      <li>Programming
        <ul>
          <li>Python</li>
          <li>Scratch (already done!)</li>
        </ul>
      </li>
    </ul>

    <h2>📖 My HTML Glossary</h2>
    <dl>
      <dt>Tag</dt>
      <dd>An HTML keyword in angle brackets, e.g. &lt;p&gt;</dd>
      <dt>Element</dt>
      <dd>An opening tag + content + closing tag</dd>
      <dt>Attribute</dt>
      <dd>Extra information added inside an opening tag</dd>
      <dt>Heading</dt>
      <dd>A title tag from &lt;h1&gt; (biggest) to &lt;h6&gt; (smallest)</dd>
    </dl>

  </body>
</html>
