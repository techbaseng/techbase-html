About This Course

Build the web from scratch.

HTML is the skeleton of every webpage. Before styling or scripting, you need HTML — the language that gives the web its structure and meaning. Designed by Babatunde Awoyemi, Techbase Consultant Services, Ibadan. 34 lessons, zero prerequisites.

  • How browsers read and render HTML documents
  • Headings, paragraphs, text formatting and links
  • Images, tables, lists and accessible forms
  • Semantic HTML — header, nav, main, footer, article
  • Responsive design and layout techniques
  • Canvas, SVG, media and HTML5 Web APIs
